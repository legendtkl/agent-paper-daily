## 更新原则

- 常态每天精选 0～2 篇，滚动 7 天通常不超过 7 篇，强论文集中时最多 10 篇。
- 自然月目标为 20～35 篇；数量是容量预算，不是配额，证据不足时允许少于 20 篇，不用弱相关论文补足。
- 总分 70 分是候选资格线，独立调研原则上选择 78 分以上的论文。
- 事实、作者主张、社区观点和调研判断分开表达；无法核验的数据明确标注。
- 原文截图仅作有限引用，标注图表编号、页码、来源和限制，不用生成图替代论文证据。
