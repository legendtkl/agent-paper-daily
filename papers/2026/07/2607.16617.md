# DataFlow-Harness：可编辑数据流水线 Code Agent

中文 | [English](2607.16617.en.md)

> 主分类：[`SE`](../../../docs/categories.md#se)；辅助分类：[`TU`](../../../docs/categories.md#tu)、[`SY`](../../../docs/categories.md#sy)

## 结论摘要

用实时 operator registry、typed mutations 和可视 DAG 让 Agent 生成平台原生数据流水线。

## 实验与证据

12 个任务、每任务 10 次运行；端到端通过率 93.3%，并报告成本与延迟下降。

## 局限与风险

任务规模较小，收益依赖特定平台资产与 operator 质量。
