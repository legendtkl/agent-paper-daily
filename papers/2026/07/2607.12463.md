# 函数感知 FIM：训练 Coding Agent 基座

中文 | [English](2607.12463.en.md)

> 主分类：[`SE`](../../../docs/categories.md#se)；辅助分类：[`PT`](../../../docs/categories.md#pt)、[`TU`](../../../docs/categories.md#tu)

## 结论摘要

从函数调用结构构造 FIM 目标，把 action-observation-continuation 归纳偏置写入代码基座。

## 实验与证据

968 个 Python 仓库、约 2.6B tokens，并覆盖 SWE-Bench、Terminal-Bench、τ-bench 与 BFCL。

## 局限与风险

主要在 Qwen 系列与 Python 语料上验证，跨模型与跨语言迁移仍不确定。
