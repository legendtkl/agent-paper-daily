# DeepSWE：用原创长程任务评测 Coding Agent

> 主分类：[`EV`](../../../docs/categories.md#ev)；辅助分类：[`SE`](../../../docs/categories.md#se)

## 结论摘要

DeepSWE 用从零编写且不回贡上游的工程任务降低公开补丁污染，并为每题编写接受多种正确实现的功能验证器。它把 Coding Agent 评测的重点从「是否复现历史补丁」转向「是否实现请求的功能」。

## 实验与证据

- 113 个原创长程任务，覆盖 91 个活跃开源仓库和 5 种语言。
- 参考解触及的代码量是 SWE-Bench Pro 的 5.5 倍，提示长度约为后者一半。
- 论文报告独立 LLM 复核与 DeepSWE 验证器的总分歧率为 1.4%，与 SWE-Bench Pro 继承测试的分歧率为 32.4%。该数字衡量判断分歧，不等于真值错误率。

## 局限与风险

原创任务降低了公开训练记录污染，但不能证明模型未见过相似仓库结构或工程模式。手写验证器成本高，也仍可能遗漏未预期的正确实现和副作用。

## 社区与复现

论文声明开放 Benchmark、验证器和完整评测轨迹。本次回溯未保存带采集时间的 Hacker News、Reddit、X 或 GitHub 互动快照，因此不推断社区共识。

## 调研判断

该工作的主要价值是重新界定 Coding Agent Benchmark 的评分责任。后续复查应关注任务许可、验证器独立审计和不同 Harness 下的排序稳定性。
