# Harness Handbook：让 Agent Harness 可读、可导航、可修改

> 主分类：[`AF`](../../../docs/categories.md#af)；辅助分类：[`SE`](../../../docs/categories.md#se)、[`SY`](../../../docs/categories.md#sy)

## 结论摘要

按行为而非文件结构生成 Harness 文档树，并让 Agent 逐级定位源码锚点。

## 实验与证据

两个开源 Harness、60 个修改请求；计划胜率提高且规划 token 下降。
