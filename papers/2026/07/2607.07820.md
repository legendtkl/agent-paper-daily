# DeepSearch-World：可验证环境中的深度搜索 Agent 自蒸馏

> 主分类：[`RA`](../../../docs/categories.md#ra)；辅助分类：[`RP`](../../../docs/categories.md#rp)、[`EV`](../../../docs/categories.md#ev)

## 结论摘要

以确定性 Wikipedia 搜索环境、过程状态和 11 轮演化式 SFT 训练深度搜索 Agent。

## 实验与证据

420K 任务；9B 模型在 BrowseComp、GAIA 和 HotpotQA 等六个基准上报告系统性提升。

## 局限与风险

离线 Wikipedia 环境可能高估结构化检索能力，真实 Web 迁移仍待验证。
