# Metis: Memory Foundation Model

## Summary

Places memory state and memory operations inside the backbone, freezing weights at inference time while updating a native memory state.

## Experiments and Evidence

Covers MemOps, LoCoMo, and NextMem; architectural ablations identify adaptive aggregation as the main contribution.

## Limitations and Risks

Fixed-capacity compression loses long-term information, and evidence from open-world, long-duration dialogue remains limited.
