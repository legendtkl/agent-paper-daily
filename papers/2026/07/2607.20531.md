# DynamicMCPBench：实时 MCP 服务上的效果评分

中文 | [English](2607.20531.en.md)

> 主分类：[`EV`](../../../docs/categories.md#ev)；辅助分类：[`TU`](../../../docs/categories.md#tu)、[`SY`](../../../docs/categories.md#sy)

## 结论摘要

DynamicMCPBench 在实时、带状态的 MCP 服务上执行成功轨迹，再将轨迹压缩成与具体调用路径无关的效果检查点。评分对象是环境是否发生预期变化，而不是最终回答或唯一工具序列。

## 实验与证据

- 24 个模型、121 个 MCP 服务器和 750 个任务，覆盖 15 类工具使用挑战。
- 使用 `pass^3`，要求三次独立运行全部成功；31% 的任务没有任何模型解出。
- 随工具链增长，准确率从最短链的 39% 降至最长链的 13%；人工验证的机会校正一致性为 0.76。

## 局限与风险

实时服务会随时间变化，提升现实性同时降低完全复现能力。`pass^3` 衡量稳定成功，不应与允许重试一次命中的 `pass@3` 混用。

## 社区与复现

论文将工作定义为可在自有服务器和任务上重跑的框架。本次回溯未保存可验证的第三方讨论链接和互动快照，不据此推断热度。

## 调研判断

该工作适合检验 MCP Agent 是否真正完成外部效果，并暴露长工具链的稳定性问题。采用时需要固定服务版本、初始状态、重试策略和验证器版本。
