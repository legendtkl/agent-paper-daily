# OSReward：跨平台 Computer-Use 奖励模型评测

中文 | [English](2607.28609.en.md)

> 主分类：[`EV`](../../../docs/categories.md#ev)；辅助分类：[`CU`](../../../docs/categories.md#cu)、[`SS`](../../../docs/categories.md#ss)

## 结论摘要

- 论文用 1,019 条跨平台人工金标准轨迹评测 27 个 VLM Judge，直接检查 Computer-Use Agent 的奖励信号是否可信。
- 困难集揭示普遍的宽松偏差：Judge 容易把「Agent 声称成功」误判为「环境状态确实成功」。
- OS-Shepherd 开放模型改善失败识别，同时论文报告其 API 等价成本比闭源方案低约 30～60 倍。
- 数据构建约消耗 800 人时；跨基准结论仍部分依赖既有验证器。

## 研究问题与背景

Computer-Use Agent 的训练和评测经常依赖视觉语言模型充当奖励模型。如果奖励模型不能可靠区分真实环境成功与语言层面的成功声明，训练信号和最终评测都会系统性偏高。

## 核心方法

作者构建跨平台人工金标准轨迹，并设置专门暴露宽松偏差的困难子集，对多类 VLM Judge 进行统一比较；随后训练开放奖励模型 OS-Shepherd，并检查成本与迁移表现。

## 实验与证据

关键规模包括 1,019 条人工轨迹、284 条困难样本和 27 个 Judge。主要证据是困难集上的失败识别差异，以及开放模型在较低成本下的表现。截图导入未随历史记录迁移，具体数值应回到论文表格复核。

## 局限与风险

人工数据成本较高，平台覆盖和任务分布可能限制外推；跨基准对照依赖既有验证器，验证器自身偏差仍可能传递。

## 复现与应用

适合用作 Computer-Use Agent 的奖励模型回归集、失败识别测试集和训练数据质量审计参考。

## 社区评价

历史采集仅验证到官方项目页与 Hugging Face 数据集活动，未保存可核验的第三方互动数值；不能据此推断社区共识。

## 调研判断

该工作直接量化奖励模型误判风险，工程价值高于单纯刷新任务成功率的工作；后续应关注数据与模型开放程度、跨平台迁移和独立复现。
