## 结论摘要

- AutoDesign 把 Harness 本身作为外循环优化对象：元优化器聚合多次 rollout 的失败证据，再让 Coding Agent 对当前 Harness 做有边界的代码更新。
- PosterBench Main Track 覆盖 5 个学科的 100 篇论文；AutoDesign 得分 78.32，比 Claude Design 高 7.45 分。
- 在 7 个模型与 Coding Agent 配置中，挂载同一 DesignHarness 后平均分从 54.99 提高到 67.39，各配置提高 5.01～19.56 分，说明收益不只来自单一模型组合。
- 一次完整长程运行包含 253 次工具调用和 11 轮编辑，40 分钟内完成，费用低于 3 美元；但方法目前只在论文转海报任务上验证，不能直接外推到通用 Harness 自动改进。
- 论文的自动优化轨迹在 80.88 附近停滞，人工指导后达到 88.39。这既支持「Harness 可学习」，也显示完全自治优化仍可能陷入局部最优。

## 研究问题与背景

现有设计 Agent 往往固定提示、工具和编辑流程，只在单个产物上迭代。成功经验与重复失败不会稳定写回系统本身。AutoDesign 研究的是更强的外循环问题：能否让一个元优化器根据一组论文转海报 rollout 的反馈，修改负责后续任务的 DesignHarness，并让改进跨论文、模型与 Coding Agent 配置迁移。

## 核心方法

内循环先解析论文元数据、章节、关键段落与视觉素材，再由 DesignHarness 生成可编辑产物。规则验证器检查渲染完整性，视觉评论模型定位内容、布局与可读性问题，Agent 以局部代码编辑修复候选并选择最佳有效结果。

外循环收集多篇论文上的成功与失败，形成重复失败模式和更新计划，只允许元优化器修改选定的 Harness 组件。优化期使用的反馈器与最终冻结的 PosterBench 评测器分离，降低直接针对最终评分器过拟合的风险。最终 Harness 再跨 7 个模型／Coding Agent 配置评测。

## 实验与证据

PosterBench 以信实性、覆盖度、信息密度、视觉证据、布局、可读性和美学 7 个维度评分，并对严重布局损坏、不可用输出和渲染失败设置上限。Main Track 有 100 篇论文，PosterBench-mini 有固定的 10 篇共享子集。

Main Track 上，AutoDesign 得分 78.32，Claude Design 为 70.87。PosterBench-mini 的 7 个受控配置中，加入 DesignHarness 后平均得分由 54.99 升至 67.39；最强 Codex 配置由 75.87 升至 81.46。完整自主轨迹执行 253 次工具调用和 11 次编辑，耗时 40 分钟、成本低于 3 美元。

论文还执行系统盲的人类偏好研究，并报告自动评分差距越大，人类与 PosterBench 的一致率越高。该证据支持评测器具有排序信息，但人类研究仍围绕会议海报，不等同于对一般设计质量的外部验证。

## 局限与风险

**作者明确边界。** 当前只验证一个输出类型和一个选定 Harness 组件；PosterBench 仍含 VLM 评分；自动外循环会停滞，需要人工指导改变搜索方向；不同模型的 API 定价会改变成本比较。

**调研推断。** 训练、反馈与最终评价虽分离，但都围绕同一任务分布，仍可能学到 PosterBench 特有偏好。100 篇论文不足以证明跨内容类型迁移。与 Claude Design 的比较包含闭源系统，无法完全统一内部工具与预算。Harness 自动修改也扩大了供应链和回归风险，部署时需要版本控制、回归集和回滚门禁。

## 复现与应用

官方仓库提供 DesignHarness、PosterBench 和示例工作流，2026-08-15 采集时为 37 stars、2 forks，仓库许可证由 GitHub 显示为非标准许可证。复现需要支持长程工具调用的 Coding Agent、浏览器／渲染工具、视觉评论模型和对应 API 预算。

较稳妥的工程用途是把外循环限制在可审计组件：先冻结评测集，记录每次 Harness 修改、失败证据和回归结果，再通过人工审查合并。尚不适合允许元优化器无门禁修改权限、凭据处理或生产发布逻辑。

## 相关工作

- [Evo-Bench](https://arxiv.org/abs/2608.09096)：评测 Agent 能否自动改进 Harness；AutoDesign 提供一个具体设计领域的端到端实例与评测集。
- [Automated Design of Agentic Systems](https://arxiv.org/abs/2408.08435)：搜索 Agent 结构；AutoDesign 更强调代码 Harness、可编辑产物和 rollout 反馈。
- [SWE-agent](https://arxiv.org/abs/2405.15793)：展示 Agent-computer interface 对编码性能的影响；AutoDesign把该接口层升级为可学习对象。
- [OpenHands](https://arxiv.org/abs/2407.16741)：通用软件开发 Agent 平台；AutoDesign 可把此类 Coding Harness 作为执行层。
