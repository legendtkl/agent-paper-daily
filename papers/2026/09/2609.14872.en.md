## Conclusion summary

- AgentKV labels an agent trajectory as think, act, tool, or others and combines recent queries from each phase to estimate future attention, reducing the bias toward the latest phase.
- The matched recent-query ablation improves average task score by 4.2 percentage points across 12 settings. It more directly isolates representative-query selection; the complete throughput gain cannot be attributed solely to phase awareness.
- Of 36 quality comparisons, only 15 against R-KV and 16 against Tri-attention have confidence intervals entirely above zero. The other 21 and 20 are statistically unresolved; no setting has a confidence interval supporting a baseline advantage.
- The authors report best output-token throughput of 1.80× relative to upstream full-KV SGLang under particular model, hardware, length, and concurrency conditions. This does not establish proportional task-latency or cost savings.
- Public phase-query-ring and eviction code was inspected, but no independent GPU benchmark was run. The paper uses q=32 while inspected implementation classes default to anchor_budget=24, requiring explicit reproduction checks.

## Research question and background

Observations include tool responses and system/user context; actions include tool-call arguments. Reasoning and execution alternate to create persistent multi-turn state. A recent-query window can describe only the current phase and undervalue older observations or constraints needed by subsequent tool calls. The paper studies internal model KV state, rather than summaries stored in an external database.

Principal-angle analysis and query visualizations show distinguishable phase-specific representation subspaces. This supports distribution shifts, but geometric separation alone does not establish benefits on every task. Executed task-quality evaluation and matched ablations provide the main evidence.

## Method

At inference time, chat-template markers, reasoning spans, tool calls, and tool responses label token phases. Each phase maintains a small FIFO query buffer; the main experiments use q=32 representatives in total. The four buffers are concatenated, all candidate keys receive mean-attention scores, and a fixed budget B is retained. Phase quotas apply to representative queries, not to four separate quotas of retained keys.

Compression triggers every 128 decoded tokens. Protected sink indices are retained, selected KV entries are gathered and physically compacted, and freed pages return to the allocator. Compressed state persists across tool responses and future turns. Model weights remain frozen, with no additional training stage.

Relative to SnapKV/R-KV, the key change is phase coverage of representative queries. Beyond logical eviction, the serving implementation handles physical compaction, allocator reuse, chunked prefill, and CUDA graphs. R-KV and Tri-attention controls sharing the serving path help separate engineering gains from retention-policy effects.

## Experiments and evidence

Models are Qwen3-8B and Qwen3-32B. BFCL web_search_base has 100 cases, multi_turn_base 200, and memory three 155-case subsets totaling 465. τ²-bench uses 50 airline, 114 retail, and 114 telecom tasks. Six domains and three budgets for each model give 36 quality settings. Evaluation follows official BFCL pass@1 and τ²-bench pass1; no training/development split is introduced.

PDF Table 3 (page 7) verifies the matched recent-query ablation: BFCL multi-turn 34.5→37.3 (+2.8), web-search 14.0→19.7 (+5.7), τ² retail 29.8→33.9 (+4.1), and telecom 11.1→15.5 (+4.4). Across all 12 settings, the average is 22.4→26.6 (+4.2). Each workload value averages three budgets and is not a benefit for one production operating point.

Appendix G and Tables 12–14 (PDF pages 15–16) provide complete paired-bootstrap 95% confidence intervals and three repeated decoding runs for representative settings. For Qwen3-32B BFCL multi-turn at B=3072, the main-table difference against R-KV is +15.0, CI [8.0,22.0]; against Tri-attention it is +1.5, CI [−5.0,8.5], statistically unresolved. Repeated-run means±standard deviations are AgentKV 40.5±1.3, R-KV 24.2±2.8, and Tri-attention 39.3±1.0. Significance against one baseline does not establish significance against another.

Serving compares SGLang 0.5.12/FlashInfer with 16k/1k or 32k/1k prompt/generation lengths, H100 NVL or RTX A6000, memory_ratio=0.90, max_prefill_length=8192, and CUDA graphs. Figure 6 (PDF page 8) reports Qwen3-32B best output throughput of 1.64×/1.80× on H100. Table 10 (page 14) gives the highest point estimate to AgentKV in all four shared-path hardware/length settings; its A6000 32k/1k value of 1.87× belongs to that separate configuration and does not replace the abstract's 1.80× result.

Figure 7 fixes Qwen3-8B, H100, 16k/1k, and batch size 16 to measure quality–throughput budget curves. AgentKV has the highest quality and throughput point estimates in six workload/budget settings, with throughput 1.18–1.22× Tri-attention and 1.61–2.08× R-KV. This does not mean all six quality differences are statistically supported.

Ablations cover phase count, query count, phase removal, label noise, and transfer to Nemotron. The authors report that 30% random phase-label corruption remains above matched R-KV; finer phase partitions can hurt at fixed q. The paper does not provide a complete ledger translating these measurements into real task cost, tool time, or tail latency.

## Limitations and risks

Author-stated limitations: KV budgets are manually chosen; capacity dominates at very small budgets, while weak compression can make policy differences smaller than execution variance. Phase-aware retention is less useful when the latest tool response or external memory already carries the state. Repetitive or degenerate reasoning can fill phase buffers with near-duplicates, requiring separate redundancy control.

Research judgment: eviction irreversibly removes state. Deployment evaluation should cover tool arguments, permission constraints, evidence provenance, and task outcomes. BFCL and simulated customer-service tasks do not represent long-running production or safety-critical workflows. Three repeats cover representative settings rather than all 36. Public attention is weak and no independent GPU reproduction was found.

Inspected StageQEvictionPlan and StageQSnapKVEvictionPlan classes default to anchor_budget=24, whereas the main paper uses q=32. Whether every runner overrides that default was not established. The inspection confirms implementation availability, not reproduction of paper scores with default installation.

## Reproduction and application

The official repository is Apache-2.0. Its engine, gorilla, and tau2-bench directories are pinned-commit submodules of the authors' kv-management-minisgl, kv-management-bfcl, and kv-management-tau2 forks. Public paths include stageq.py, query_ring.py, manager.py, attention_score.py, and experiment runners. README requires recursive cloning, Linux, an NVIDIA GPU, and a recent CUDA toolkit; the engine JIT-compiles CUDA/Triton. Mini-SGLang and τ²-bench are MIT, BFCL is Apache-2.0; third-party assets retain their licenses.

Reproduction should pin repository/submodule commits, model versions, q, B, compression interval, parser mapping, redundancy terms, calibration statistics, concurrency, and sampling configuration. Tri-attention requires external calibration statistics. README refers to NOTICE, but the inspected root listing lacks that file, so attribution requires further checking.

This run statically checked the paper, public directories, README, and phase-eviction source. It did not independently run GPU evaluation or performance tests. The method suits open-model serving teams controlling KV lifecycles; remote model APIs cannot directly install it. Select B against actual multi-turn task-quality targets, then measure completion, tokens/s, TTFT, p95 latency, and memory usage rather than applying the maximum speedup universally.

## Related work

- SnapKV (https://arxiv.org/abs/2404.14469): selects KV using attention from a short observation window; AgentKV changes phase coverage of representative queries.
- H2O (https://arxiv.org/abs/2306.14048): retains accumulated-attention heavy hitters; AgentKV explicitly represents a phase mixture.
- StreamingLLM (https://arxiv.org/abs/2309.17453): preserves attention sinks and a sliding window, providing a related stable streaming-context strategy.
- ReAct (https://arxiv.org/abs/2210.03629): alternates reasoning and actions, motivating phase-structured agent trajectories rather than KV compression itself.
