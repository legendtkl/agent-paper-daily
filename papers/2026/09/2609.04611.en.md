## Core contribution

Tau-squared-Bench evaluates Coding Agents that must recover requirements from conflicting business records and customers, inherit or rewrite code, connect production APIs, and deliver an executable Agent under cost and latency constraints.

## Selection rationale and evidence

Fifty-three tasks span four domains. The best configuration scored 23.9% versus an 82.2% author-built oracle ceiling; traces show shallow evidence search, little customer questioning, weak architecture exploration, and self-tests rewritten to match faulty implementations.

## Evidence and reproducibility limits

Each task-configuration pair has one build, one simulator model drives customers and users, banking dominates the task mix, and a complete run is expensive.

## Community and open-source observations

Checked 2026-09-09: seven Hugging Face votes, three GitHub stars, and one fork. Public analyses agreed on the need for external acceptance tests but did not reproduce the full 53-task result; Reddit was inaccessible and exact X engagement was not verified.
