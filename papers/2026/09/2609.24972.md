## 结论摘要

- RRSI 把 Harness 自我改进中的过拟合视为搜索正则化问题：候选生成端限制同时修改的组件并鼓励探索新路线，候选选择端过滤基准特定改动、噪声收益和无效复杂度。
- 论文覆盖 Coding、Agentic Workspace 和工程设计 3 个领域、8 个基准；在演化集上最高提高 14.1 分，在 5 个分布外基准上最高提高 4.7 分。
- 相比无正则演化，最终 Harness 的 policy tokens 减少约 30%，说明正则化没有用更高推理成本换取泛化收益。
- 逐项消融显示退火编辑预算、进化历史探索、critic 和 pruner 分别约束候选复杂度、重复搜索、基准泄漏和噪声累积；组合效果优于单一约束。
- 证据来自作者环境和冻结模型，尚无独立完整复跑；外部模型／环境调用仍昂贵，结论不能外推为任意 Agent 都会持续递归改进。

## 研究问题与背景

Harness 包含提示词、控制流、工具、记忆和上下文管理。同一冻结模型可因 Harness 不同产生显著能力差异，因此近期工作让 LLM 根据失败轨迹自动修改 Harness。但反复用有限演化集选择改动，会把任务特定模式、评分噪声或多余组件写进系统，在演化集上提升、在新任务上退化。

RRSI 研究部署后持续修改 Harness 的机制，主分类为 `LT`；被修改对象是 Agent 架构与编排，对应 `AF`；token、运行复杂度与执行开销对应 `SY`；演化集—分布外拆分和八基准协议对应 `EV`。

## 核心方法

RRSI 保持 Harness 全部组件可编辑，但在「提出—评估—选择」循环中增加四类约束。Annealed Budget 让早期候选可以探索多个改动，随后逐步收紧每个候选包含的编辑数量，降低复杂度堆叠。Evolution History 把已有改动和失败路线反馈给 proposer，鼓励搜索尚未覆盖的机制。

选择端的 critic 检查候选是否引用演化集特定文本、验证器或其他不可迁移信息；pruner 删除太小、太贵或在后续版本中不再有效的改动。候选只有在性能、成本和泛化风险之间通过门槛，才进入下一轮 Harness。

该方法不修改基础模型权重，改进保存在可读的 Harness 组件中；因此可以审计每轮差异，也能把最终 Harness 迁移到不同任务、工具接口或 verifier 上。

## 实验与证据

实验覆盖 8 个基准、3 个领域，并明确区分用于演化的 split 与 5 个分布外基准。RRSI 在演化集上的最大收益为 14.1 分，在 OOD 上最大为 4.7 分；多个无正则或弱约束演化基线保留不了演化集收益，部分甚至低于初始 Harness。

论文比较初始 Harness、四类基线和 RRSI，并报告逐轮曲线、跨域迁移、组件消融和 token 成本。RRSI 在 SWE-bench Verified、JobBench／GDPval／APEX-Agents 汇总与 Frontier-Eng 等分布外条件上保持正向改进。相对无正则演化，policy tokens 减少约 30%。

消融表明只限制编辑数量不能覆盖基准泄漏，只使用 critic 也不能阻止历史复杂度累积；proposal 和 selection 两侧同时正则化时，迁移收益和效率最好。论文还公开最终 Harness 与演化记录，便于核对具体改动是否包含任务特定硬编码。

## 局限与风险

作者实验仍依赖有限的演化集、冻结策略模型和特定 Harness 表示。虽然覆盖三个领域，八个基准不足以证明对所有数字 Agent、GUI 或具身任务都泛化。外部模型和可执行环境的构建成本没有被简化为统一总成本，30% policy-token 降幅也不等于训练／演化总成本降低 30%。

调研推断：critic 本身由模型判断，可能漏掉语义形式的基准特化；pruner 会偏向短期可测量收益，可能删除需要更长时间显现的能力。递归自我改进发生在 Harness 层，不等于模型权重、研究目标或安全边界能够自主可靠改进。

代码与测试公开提高可复现性，但采集时未见第三方完整重放八基准。GitHub stars 和 HF votes 反映关注与工件可用性，不构成结果复现。

## 复现与应用

官方仓库提供 RRSI 实现、领域适配、测试和评测脚本，采用 Apache-2.0。复现需要固定基础模型、Harness 初始版本、演化／评测 split、调用预算、并发和 verifier；同时记录每轮候选、筛选原因、policy tokens 与最终 OOD 结果。

适用于 Coding Agent、研究 Agent 和企业工作流 Harness 的持续改进。工程采用时应把演化任务与晋级任务隔离，冻结隐藏回归集，限制单轮变更规模，并保留可回滚版本，不能只依据演化集分数自动上线。
