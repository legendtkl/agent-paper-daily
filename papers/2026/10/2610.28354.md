## 结论摘要

- S-Agent 2.0 不训练专用控制器，而是给通用 Coding Agent 增加命令行感知工具、持久场景记忆和自然语言空间读数，让「取证—记忆—解释」形成可检查循环。
- 在 Qwen3.8-27B 上，系统在 MMSI-Bench／ReVSI 达到 66.5／82.3，较同骨干无工具 Agent 提高 13.9／20.5 分，较 SpatialClaw 提高 3.9／7.8 分。
- 接口消融支持核心机制：去掉场景记忆下降 3.5／2.5 分，去掉解释性读数下降 1.3／1.2 分，去掉模型感知接口下降 8.8／5.9 分。
- 结果证明的是完整 Agent 与感知后端组合，不代表纯语言模型获得了内生 3D 能力；重建、分割和运动估计依赖多项外部模型。
- 公开代码、运行轨迹和三种 Coding Agent Harness 对照提高可核验性，但本次只完成静态编译，没有重跑 GPU 服务和五个基准。

## 研究问题与背景

现有空间推理 Agent 已能调用深度、分割和三维重建工具，但「工具返回正确数值」不等于「模型能把数值转换成题目要求的空间关系」。作者观察到两类常见失败：模型把正确读数解释反了，或后续查看图像时推翻了先前工具证据。研究问题因此不是继续增加工具，而是如何让工具证据保持可寻址、与模型观察进入同一场景，并在返回时直接映射为题目使用的空间语言。

## 核心方法

**通用 Coding Agent。**OpenHands 默认承担规划、Shell、文件与图像读取；同一工作区也可由 Codex 或 Claude Code 驱动，不需要专用 Agent 控制器。

**场景记忆。**`recon` 将全部帧重建为统一、重力校准的三维场景，`segment` 将文本目标注册为实例；Agent 也能用 `add_instance` 写入自身识别的观察者、锚点或对象，并用 `drop` 删除错误实例。

**解释性读数。**`distance`、`side`、`elevation`、`motion` 与 `compass` 等命令同时返回数值、单位和面向当前问题选项的自然语言结论，减少模型自行完成坐标转换时的错误。

**检查与修正。**工具输出写入文件，Agent 可查看分割叠图、鸟瞰图与场景注册表；当视觉观察和记忆冲突时，可修改实例后重新查询。

## 实验与证据

论文覆盖 MMSI-Bench、MindCube、SPAR-Bench、MMSI-Video 与 ReVSI 五个多视角或视频空间推理基准。Qwen3.8-27B 下，S-Agent 2.0 分别取得 66.5、88.3、72.4、56.4、82.3，五项均高于 SpatialClaw 的 62.6、83.2、70.2、53.1、74.5。

同骨干工具对照更能隔离接口价值：Qwen3.8-27B 的通用 Coding Agent 在 ReVSI／MMSI 从 61.8／52.6 提高到 82.3／66.5；Gemini-3.8-Flash 从 80.9／62.9 提高到 90.5／74.1。三种 Harness 对照中，OpenHands、Codex、Claude Code 在 MMSI 为 66.5／67.0／63.8，在 ReVSI 为 82.3／76.6／79.1，说明工具接口并非只适配一种循环。

附录统计三组各 1,000 个 episode 的工具使用；重建在所有 episode 中调用，分割和鸟瞰图覆盖超过 90%。`drop` 在 21%～40% 的 episode 中出现，说明修正场景记忆不是少数展示案例。

## 局限与风险

论文没有单列完整限制章节，也未报告主表的跨随机运行方差或端到端成本。五个基准使用不同官方协议，准确率与数值题的相对准确率不宜直接横向比较。部分专有模型对照来自既有报告，Harness、上下文与推理预算不完全一致。

完整系统同时依赖 Qwen3.8-27B 或托管模型、Depth Anything 3、SAM 3、GeoCalib、LoMa、Pi3MOS、GPU 服务与容器运行时。`agent/` 与文档为 Apache-2.0，但 `perception/` 包装的 SpatialClaw 延续 NVIDIA 非商业许可证；工程复用不能只看顶层许可证。

剩余错误集中在观察者视角想象和「位置高度／物体自身高度」等语义边界。持久场景记忆也可能持久保存错误实例；生产系统仍需来源标记、冲突处理和过期机制。

## 复现与应用

官方仓库固定到 commit `c99526846220534e02f1bfb7498c7f8e2201f3df`。本次执行 `python3 -m compileall -q agent` 通过，仅出现一处既有无效转义 SyntaxWarning；未启动四个服务、下载模型权重或重跑五基准。代码仓库包含任务配置、网关、基准加载器、运行脚本和论文轨迹，足以审计接口，但完整复现需要多 GPU 后端和外部基准数据。

适用方向包括多视角问答、机器人空间感知、视觉检查 Agent，以及任何需要把模型观察和工具测量合并为持久证据的 Harness。
