## Conclusion summary

- TraceTrial-Bench separates agent task completion from seven harness mechanisms: context, execution, governance, lifecycle, observability, tools, and verification.
- Ninety-five tasks across Claude Code, Codex, OpenClaw, and DeepSeek Harness with nine models produce 3,420 evaluation cells. Harness macro averages range from 59.8% for Codex to 72.0% for OpenClaw.
- 31.1% of runs pass the agent criterion but fail at least one harness criterion; only 8.4% satisfy the paper's clean-success definition. Terminal outcomes systematically miss governance and lifecycle defects.
- The repository exposes all 95 tasks, evaluators, configurations, and runners. Static compilation and a CLI smoke test passed locally, but the complete archive of 3,420 result traces is absent.

## Research question and background

Most agent benchmarks collapse model, harness, and environment into one score. A failure can originate in reasoning, context truncation, execution, permissions, cleanup, observability, or verification; success can conceal overreach or state leakage. The paper asks how to compare native harnesses semantically while retaining auditable, mechanism-level evidence.

## Method

TraceTrial-Bench defines 95 expert-authored tasks over seven reliability dimensions. Trajectory Tracing records model context, harness events, and environment state. Multi-source Evidence Acquisition organizes those streams for a semantic judge. Failure Attribution uses explicit mechanism chains to produce run-level candidate explanations.

Scoring has two layers: agent completion and harness compliance. Executable or state-based ground truth supports semantic equivalence while each harness retains native commands, context, and governance. Crucially, candidate mechanism chains are evidence-consistent hypotheses, not causal claims.

## Experiments and evidence

- Four harnesses, nine models, and 95 tasks form 3,420 cells; each cell uses one selected execution, with no within-cell stability estimate.
- Harness macro averages are 59.8% for Codex, 65.2% for DeepSeek Harness, 71.8% for Claude Code, and 72.0% for OpenClaw. Model overall scores range roughly from 66.9% to 73.3%.
- Claude Code has a 44.0% Agent Pass rate but a 73.5% Harness Overall score, demonstrating distinct model and harness axes.
- 31.1% pass the agent condition while failing a harness condition; only 8.4% are clean successes. This directly motivates two-layer scoring.
- All semantic judging uses deepseek-v4-flash. Cost tables exclude judge cost and contain estimates rather than invoices, weakening cost comparisons.
- Case studies illustrate mechanisms, but the paper does not systematically estimate candidate-link precision, recall, judge agreement, or human-review coverage.

## Limitations and risks

The authors explicitly acknowledge targeted tasks, uneven mechanism coverage, one selected execution per cell, limited generalization, and changing harness/model/runtime/scoring versions. Preserving native behavior increases ecological validity but weakens variable control.

A fixed semantic judge propagates its bias to every comparison; benchmark authors also design the tasks; 31.1% is not a production incident rate and 8.4% is not a universal agent success rate. Mechanism chains should be treated as audit leads, not root-cause determinations.

Python static compilation passed and the CLI help entry point ran locally. The roughly 2,020-file repository includes tasks, environments, scoring configuration, and limited formal-result examples.

The framework is useful as a harness acceptance checklist, incident-audit structure, and regression-task source. ## Related work

- [Terminal-Bench](https://arxiv.org/abs/2504.07314): terminal-agent capability evaluation; TraceTrial extends the target to harness mechanisms.
- [SWE-bench Pro](https://arxiv.org/abs/2509.16941): harder software-engineering tasks, still centered on task outcomes.
- [Harness-Bench](https://arxiv.org/abs/2509.07774): direct harness comparison and the nearest benchmark direction.
- HarnessAudit and HarnessRisk: harness behavior and risk auditing; TraceTrial adds cross-harness tasks, traces, and mechanism chains.
- AgentRx and REFLECT: trajectory-based diagnosis or reflection; this paper explicitly separates agent and harness layers.

## Research judgment

- Reading priority: high. It separates model capability from harness reliability and turns that distinction into an executable audit framework.
- Confidence: medium-high. Tasks, code, and scoring structure are public across four harnesses and nine models; single executions, one judge, and incomplete result archives limit repeatability.
- Audience: agent-platform, runtime, reliability, safety, and evaluation teams.
- Watch next: full trace release, repeated cells, multi-judge agreement, human precision of mechanism chains, and ranking stability across harness updates.
