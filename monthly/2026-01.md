## 月度主题

**研究重心从「给模型增加 Agent 外壳」转向状态管理、可执行环境与过程诊断。**

1 月的高密度方向是记忆和长时任务：Agentic Memory、SimpleMem、SYNAPSE、TiMem、MemRL 与 Mem-Gallery 分别处理可学习的记忆操作、压缩、关联检索、时间层级、运行时更新和多模态评测。另一个明显变化是把 Agent 的失败拆成可测对象：API 噪声、工具选择、多 Agent 方差、代码上下文、研究检索与分类组织不再只由最终答案分数覆盖。

## 趋势分析

### 1. 记忆从检索附件变成可学习的状态策略

本月 6 篇记忆论文形成清晰分工。Agentic Memory 把记忆操作加入策略动作空间；MemRL 在不更新权重时根据环境回报调整经验效用；SimpleMem、SYNAPSE 与 TiMem 分别处理压缩、关联和时间层级；Mem-Gallery 则开始检验图像与文本跨会话保留。方向变化不是单纯扩大上下文，而是回答「何时写、写什么、如何组织、如何确认记忆影响后续行动」。

### 2. 可执行环境同时成为训练数据源和评测器

WebGym 与 InfiniteWeb 都把环境规模作为训练瓶颈，前者扩展真实网站任务和 rollout 吞吐，后者自动生成带任务评测器的功能网站。HardGen 从失败轨迹生成困难工具样本，RepoReason 用程序执行产生代码推理真值。这些方法共同减少仅靠静态指令数据和 LLM Judge 的依赖，但环境真实性、任务泄漏与评测器正确性仍需独立审计。

### 3. 最终分数不足以解释 Agent 失败

MAESTRO 记录系统轨迹、时延和成本；WildAGTEval 拆分 API 规范与执行复杂度；RepoReason 评估代码上下文整合；TaxoBench 分离研究检索与分类组织。月内工作正在建立可定位的中间指标，使「模型能力不足」「Agent 架构不稳」「工具执行异常」和「评测器失真」不再混为同一类失败。

### 4. 长时规划开始处理初始决策与显式状态

WebAnchor 发现首个计划步骤对后续行为有不成比例的影响，MobileDreamer 用世界模型预测 GUI 动作后状态，InfiAgent 则通过文件状态把上下文长度与任务时长解耦。三者分别从信用分配、未来预测和运行时状态处理长时任务，说明扩大模型上下文并非唯一技术路径。

### 5. 多 Agent 的价值转向可复现与成本约束

M3MAD-Bench 与 MAESTRO 都显示，多 Agent 方案需要在重复运行、Token、时延和架构差异下比较，而不能只展示单次准确率。O-Researcher 的多 Agent 主要用于生成训练轨迹，EvoRoute 则以经验路由控制资源。多 Agent 开始从固定角色提示词转向可测的组织与资源决策。

## 证据与复现限制

- 核心贡献和数值来自 arXiv 摘要；未逐一复算论文表格，也未在统一硬件和 Agent Harness 上复现实验。
- arXiv 预印本可能继续修订。本文按 `v1` 日期归档，但标题、摘要、代码状态和结果可能在后续版本变化。
- 论文自报的开放代码、数据或计划开放不等于仓库完整、许可证明确或结果可重现；本月未系统核验依赖、数据可得性与提交哈希。
- 24 篇是按既定范围筛选的研究样本，不代表 1 月全部 Agent 论文，也不能直接解释为领域绝对热度。
- 多篇工作使用不同模型、环境、预算与 Judge，表中数值不能横向组成排行榜。

## 后续观察

- MCP 是否从单 Server 工具调用扩展到跨 Server 事务、权限边界和执行后效果核验。
- 记忆评测是否从问答召回转向多会话任务中的行动收益、错误积累和安全遗忘。
- Agent RL 是否形成低成本、可验证的中间信用分配方法，而不是只依赖轨迹终态奖励。
- GUI、Coding 与研究 Agent 是否公开可持续运行的环境、轨迹和评测器，支持跨框架复现。
