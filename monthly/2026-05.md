## 月度主题

**记忆从独立组件转向完整生命周期，技能与 Harness 开始被视为可执行、可审计的系统边界。**

5 月的主线不是单纯扩大记忆容量，而是同时处理记忆的结构化、迁移、形成时机、跨场景评测和安全来源。另一条清晰变化是：技能不再只是提示文本，研究开始测量技能库扩张、技能生成、运行时干预和供应链风险。评测也由终态成功率向控制决策、轨迹质量、权限与信息流转移。

## 趋势分析

### 1. 记忆研究由「能否召回」转向完整生命周期

本月条目同时覆盖记忆格式、形成时机、巩固成本、跨模型迁移、多人状态、来源链和跨环境评测。LongMemEval-V2、EvoMemBench 与 MemGym 还分别从经验问答、统一协议和可执行环境隔离记忆贡献。由此可见，单一对话问答分数已不足以代表 Agent 记忆。

### 2. 技能成为可执行工件，也成为新的安全主体

HASP 将技能改造成可触发的程序函数；SkillGenBench 直接评测技能生成；技能规模律说明技能库扩张会引入路由衰减；AgentTrap 则测量第三方技能在真实运行时造成的副作用。共同变化是技能需要版本、权限、执行和评测语义，而不只是自然语言说明。

### 3. 评测从终态正确扩展到轨迹、控制与信息流

HarnessAudit、AgentAtlas、POLAR-Bench 与 AgentSecBench 分别关注权限边界、控制决策、隐私—效用和非干扰。它们共同反对只看最终答案：任务完成过程中发生的未授权读取、信息泄露或错误控制同样属于失败。

### 4. Agent 训练开始组合稀疏终态奖励与局部反馈

SDAR 和 SERL 都保留环境终态奖励的主导作用，再用 token 级教师信息或步骤级环境反馈改善长程归因。重点不再是简单增加监督密度，而是控制反馈的可信度、位置和权重，避免错误教师或无关上下文反向干扰策略。

### 5. Harness 与上下文服务成为可测量变量

Agentic Search 的实验表明，相同检索算法在不同 Harness 和工具返回方式下会得到不同结果；Parallel Context Compaction 与 RecMem 则把延迟、写入成本和压缩调度纳入研究。后续比较模型或算法时，需要固定或显式报告 Harness、状态管理和服务策略。

## 后续观察

- 技能权限是否从离线扫描转向运行时能力控制，以及 MCP 工具面是否出现更明确的授权语义。
- 记忆系统能否跨任务、跨模型保持收益，并报告构建、检索、生成三个阶段的成本。
- 长程训练能否在不同环境中稳定迁移，且避免由错误反馈造成策略退化。
- 过程级评测是否开始配套可重放轨迹、确定性判定器和失败定位工具。
