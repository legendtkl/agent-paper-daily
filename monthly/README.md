# 月度归档

中文 | [English](README.en.md)

每月 1 日汇总上一个完整自然月。月度目标为 20～35 篇，但数量不是配额；常态归档只汇总每日已入选论文，不进行第二轮扩选，明确要求的历史回溯补录会单独标注。

每份月报包含逐篇核心贡献与入选证据、方向分布、至少 3 个趋势分析主题、社区与开源观察、证据限制和后续观察。作者报告、社区观点和调研判断分开表达。

跨月方向变化见 [2026 年 Agent 论文趋势（1—7 月）](../docs/2026-trends.md)。
