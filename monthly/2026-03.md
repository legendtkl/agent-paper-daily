## 月度主题

**Agent 研究开始把执行过程本身变成可训练、可观测、可治理的系统对象。**

本月不只有模型能力或最终成功率的比较。评测工作下沉到步骤、约束和审计器可靠性；系统工作把调度、上下文、进程和 Harness 作为独立设计层；记忆研究也从「保存更多」转向检索瓶颈、控制流风险和主动遗忘。与此同时，工具训练开始强调可执行验证、数据多样性和环境稳定性。

## 趋势分析

### 1. 评测从最终答案下沉到步骤、约束和评测器

ASTRA-bench、AgentProcessBench 与 CCTU 分别增加了个人上下文复杂度、步骤级人工标签和可执行约束检查。CUAAudit 又进一步测量自动审计器的准确率、校准和分歧。变化不只是基准变长，而是要求回答「在哪一步失效」「是否违反约束」「Judge 是否可靠」。

### 2. Harness 和运行时成为独立研究层

OPENDEV、AgentRM、Quine 与 AgentOS 从不同层次讨论模型外系统。前两者提供实现与系统指标，Quine 尝试复用 POSIX 进程语义，AgentOS 则提出更宽的操作系统议程。共同变化是：调度、上下文压缩、隔离和状态生命周期不再被视为提示词附属细节。

### 3. 记忆研究从「存什么」转向「何时读、如何控制」

检索瓶颈研究表明，当前管线中检索选择的影响可能大于复杂写入；MemoryCD 把评测推向多年跨领域行为；Oblivion 开始显式控制读写与衰减。与此同时，MEMFLOW 表明持久记忆还能改变工具控制流，说明效用与安全需要共享同一套记忆治理接口。

### 4. Agent 训练依赖可执行性、多样性和环境稳定性

CoVe 用约束把数据生成与验证绑定，DIVE 从真实工具轨迹反推任务，长时工具 RL 研究则把环境稳定性列为核心轴。训练数据不再只追求更多指令，而是要求轨迹可执行、结果可检查、结构分布可控制。

### 5. Computer Use 转向专业软件、连续视频和可复用技能

OSExpert 通过环境探索形成程序性技能，CUA-Suite 提供专业应用的连续人类演示，视频奖励模型则直接从执行视频判断结果。三者分别补充技能获取、训练数据和结果监督，显示 GUI Agent 的研究单位正从单次点击扩展到完整时序任务。

## 证据与复现限制

- 本月 25 篇是主题精选，不代表完整文献计量结果；数量不能直接解释为方向热度。
- 表中实验规模和性能数据来自论文摘要，尚未逐项独立复现；正式引用前需回到正文核对任务设置、基线和统计方法。
- arXiv 论文可能继续修订。标题、代码状态和结果应以访问时的最新版本为准；本页的归月依据固定为首次提交日期。
- AgentOS 与 Bootstrapping Coding Agents 含有明显的概念或个案性质，其价值主要是提出系统边界和设计假设，不能与多基准实证工作等量解释。

## 后续观察

- 过程评测是否形成跨环境通用的错误分类与 Judge 校准协议。
- Harness 是否从经验性实现走向显式状态契约、可回滚修改和可重复系统基准。
- 记忆遗忘、删除与隐私治理能否同时给出效用保持和攻击恢复证据。
- 专业 Computer Use 是否增加重复运行、人工基线和跨应用任务，而不只扩大截图或任务数量。
