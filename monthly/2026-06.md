## 月度主题

**评测进入长流程、动态故障和真实工作环境，Agent 基础设施开始同时承担训练、权限、可观测与自修复。**

6 月的论文把「运行时是否可靠」拆成多个可测问题：工具失效后的重规划、第三方技能注入、SaaS 集成中的间接注入、轨迹来源证明、Harness 缺陷定位和能力最小化。规划基准扩大了工具数量、隐藏约束和任务时长；OSWorld 2.0 与 SWE-Interact 则把真实桌面工作流和用户逐步澄清需求带入评测。

## 趋势分析

### 1. 规划评测由静态方案转向动态约束与故障恢复

APB 先隔离规划本身，AdaPlanBench 逐步揭示用户和世界约束，ToolMaze 注入工具故障，PlanBench-XL 再扩大工具集合并限制可见性。它们共同把「会生成计划」与「能在信息不全、工具异常时持续修订计划」区分开。

### 2. 安全边界下沉到技能、MCP 服务和运行时能力

SkillGuard 把技能视为权限主体，SafeMCP 在服务端控制能力获取，Agent libOS 以显式 capability 管理资源权力，AgentRedBench 则覆盖真实 SaaS 集成返回内容。防御对象从模型文本扩展到完整执行栈，且更重视权限变化和中间轨迹。

### 3. Harness 从固定外壳变成可演化、可修复的系统

Adaptive Auto-Harness 面向开放任务流维持多套 Harness 并做路由；HarnessFix 将失败定位到具体运行时工件；Lean4Agent 使用形式化语言检查工作流语义。变化说明 Harness 已同时承担适应、诊断、验证和治理，而不只是工具调用封装。

### 4. Agent 训练与执行基础设施进一步分离

SIRI 尝试把经过验证的技能内化进策略，减少推理时技能库依赖；AgentJet 则将训练服务器与环境客户端解耦，以支持异构模型、任务隔离和故障恢复。训练研究开始同时优化策略信号和运行环境的可操作性。

### 5. 基准开始接近真实工作时长与人机协作

OSWorld 2.0 将桌面任务推进到数百步、小时级工作流；SWE-Interact 不再一次给全需求；MCP-Persona 引入个人应用状态；WebChallenger关注网页结构记忆和复合动作。这些环境更容易暴露隐式状态、需求澄清、过程验证与长期约束遗忘。

## 后续观察

- 长程基准能否提供可重放环境、成本报告、部分完成度和中间失败标签，而不只发布终态成功率。
- MCP 与技能生态是否形成跨实现一致的权限、来源和用户确认语义。
- 自演化 Harness 是否具备回滚、回归测试、变化审计和分布漂移检测。
- Coding Agent 与 Computer Use 是否继续从单轮自主执行转向含糊需求澄清、跨应用状态和人工监督。
