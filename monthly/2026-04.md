- 元数据依据：每篇论文的 arXiv 摘要页与官方 API；日期取首次提交日期，标题保留官方写法。

## 月度主题

**从「Agent 能否完成任务」转向「环境、Harness、验证器和权限能否共同支撑稳定执行」。**

本月出现多个规模更大、任务更长的 Computer Use 与工具基准，也出现针对生产 Coding Agent、真实专业软件和重复运行稳定性的评测。与此同时，运行时研究开始为状态、调度和 Harness 定义更显式的契约；安全工作从静态沙箱延伸到最小能力集、后门工具和长序列危害。

## 趋势分析

### 1. 环境规模扩大后，评测重点转向任务真实性与重复可靠性

Gym-Anything 将环境覆盖扩到 200 个软件和 1 万余个任务，FrontierFinance 与 WindowsWorld 分别加入专家级长任务和跨应用职业流程。与此同时，On the Reliability of Computer Use Agents 要求重复执行同一任务。基准规模不再只是题目数量，还包括人类工时、步骤长度、应用组合和跨运行方差。

### 2. 验证器不再被视为无误差基础设施

Universal Verifier 讨论 Rubric、过程奖励和长轨迹上下文；AgentProp-Bench 用人工子集测量 Judge 一致性；IntentScore 则把动作级奖励用于运行时重排。三类工作分别处理结果判断、Judge 校准和行动前选择，说明训练奖励、排行榜与在线恢复共享同一验证可靠性问题。

### 3. Harness 从隐式循环走向显式状态和可观测修改

ClawVM 为上下文与持久状态定义最低保真和写回约束，结构化图 Harness 把计划、执行和恢复分层，AHE 要求每次 Harness 修改都留下可验证预测。对比 3 月的运行时探索，本月更强调状态契约、归因和回滚条件，而不只是新的 Agent Loop。

### 4. 工具研究同时走向统一表示与经验性反证

UniToolCall 统一训练和评测表示，COVERT 保持 Oracle 地增加噪声与含混条件，GTA-2 从原子调用扩到开放工作流。The Tool Illusion 则提醒工具收益可能受模型、框架和基准设置影响。工具数量、调用成功率和真实任务完成率需要分开报告。

### 5. 安全边界从容器隔离扩展到能力、记忆和长序列

AgentHazard 评估局部合理动作累积成危害，Back-Reveal 利用记忆与工具组合外泄数据，Aethelgard 尝试按任务缩减能力集，Secure Forgetting 则测试删除后能否抵抗推断。共同方向是用显式能力和信息流约束补充静态沙箱。

## 证据与复现限制

- 本月 24 篇是主题精选，不代表完整文献计量结果；数量不能直接解释为方向热度。
- 表中实验规模和性能数据来自论文摘要，尚未逐项独立复现；正式引用前需回到正文核对任务设置、基线、失败样本和统计方法。
- arXiv 论文可能继续修订。标题、代码状态和结果应以访问时的最新版本为准；本页的归月依据固定为首次提交日期。
- From Agent Loops to Structured Graphs 明确属于立场与设计提案；Beyond Static Sandboxing 的摘要也没有提供与其框架范围相称的完整实证。两者不应与公开大规模基准的证据强度等量解释。

## 后续观察

- 更大环境是否能提供稳定镜像、版本锁定、可重置状态和成本可控的训练接口。
- 自动 Judge 是否报告人工一致性、校准误差和不同失败类型下的误报／漏报。
- Harness 自动优化能否跨仓库、跨模型、跨任务保持收益，并提供负向修改和回滚记录。
- 最小权限、状态删除与工具供应链防护能否形成可组合、可审计的统一运行时策略。
