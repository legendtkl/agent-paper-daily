# Agent Papers Monthly Review | 2026-01

[中文](2026-01.md) | English

> Type: historical retrospective. This review is organized by the UTC first-submission date of arXiv `v1` and was compiled retrospectively on 2026-08-02. These entries are not presented as results of a daily selection process that was already running in January.

## Scope and Count

- Period: 2026-01-01 to 2026-01-31, based on the first submission date of arXiv `v1`.
- Selected: 24 papers. Each paper's ID, official title, first submission date, and abstract were checked directly against its official arXiv abstract page.
- Research scope: agent architectures and runtimes, tool use and protocols, memory, agent training, multi-agent systems, computer use, coding agents, research agents, evaluation, and safety.
- Selection boundary: priority was given to work proposing verifiable mechanisms, environments, datasets, or diagnostic methods. Papers that merely wrapped an LLM in a vertical application without an agent-specific contribution were excluded.
- Date note: MCP-Atlas has the identifier `2602.00933`, but its official submission history lists `v1` as 2026-01-31, so it is included in January.

## Monthly theme

**The research focus shifted from “adding an agent wrapper to a model” toward state management, executable environments, and process diagnostics.**

January's densest cluster concerned memory and long-horizon tasks. Agentic Memory, SimpleMem, SYNAPSE, TiMem, MemRL, and Mem-Gallery respectively addressed learnable memory operations, compression, associative retrieval, temporal hierarchy, runtime updates, and multimodal evaluation. Another clear change was the decomposition of agent failures into measurable objects: API noise, tool selection, multi-agent variance, code context, research retrieval, and taxonomy organization were no longer hidden behind final-answer scores alone.

## Trend analysis

### 1. Memory Became a Learnable State Policy Rather Than a Retrieval Add-On

The six memory papers this month show a clear division of labor. Agentic Memory adds memory operations to the policy action space; MemRL adjusts experience utility from environment rewards without updating model weights; SimpleMem, SYNAPSE, and TiMem respectively address compression, association, and temporal hierarchy; Mem-Gallery begins to test cross-session retention of both images and text. The shift is not simply toward larger contexts, but toward answering when to write, what to write, how to organize it, and how to verify that memory affects subsequent actions.

### 2. Executable Environments Became Both Training Sources and Evaluators

WebGym and InfiniteWeb both treat environment scale as a training bottleneck: the former scales real-website tasks and rollout throughput, while the latter generates functional websites with task evaluators. HardGen produces difficult tool-use samples from failed trajectories, and RepoReason uses program execution to establish code-reasoning ground truth. Together, these methods reduce reliance on static instruction data and LLM judges alone, although environment realism, task leakage, and evaluator correctness still require independent auditing.

### 3. Final Scores Were No Longer Sufficient to Explain Agent Failures

MAESTRO records system traces, latency, and cost; WildAGTEval separates API-specification and execution complexity; RepoReason measures code-context integration; TaxoBench separates research retrieval from taxonomy organization. Work this month began to establish localizable intermediate metrics, preventing model limitations, unstable agent architecture, tool-execution errors, and evaluator distortion from being collapsed into the same failure category.

### 4. Long-Horizon Planning Began to Address Initial Decisions and Explicit State

WebAnchor finds that the first planning step has a disproportionate effect on later behavior, MobileDreamer predicts post-action GUI states with a world model, and InfiAgent decouples context length from task duration through file-based state. The three approaches address long-horizon tasks through credit assignment, future prediction, and runtime state, respectively, indicating that increasing model context is not the only technical path.

### 5. Multi-Agent Value Shifted Toward Reproducibility and Cost Constraints

Both M3MAD-Bench and MAESTRO show that multi-agent approaches must be compared across repeated runs, tokens, latency, and architectural differences rather than by a single accuracy result. O-Researcher primarily uses multiple agents to generate training trajectories, while EvoRoute uses experience-based routing to control resources. Multi-agent research began to move from fixed role prompts toward measurable organizational and resource decisions.

## Evidence and reproducibility limits

- Core contributions and numerical results are taken from arXiv abstracts. Tables were not independently recomputed, and experiments were not reproduced across a shared hardware setup and agent harness.
- arXiv preprints may continue to be revised. This review is organized by `v1` date, but titles, abstracts, code status, and results may change in later versions.
- Author-reported open code, data, or plans to release them do not establish repository completeness, licensing clarity, or reproducibility. Dependencies, data availability, and commit hashes were not systematically verified this month.
- The 24 papers are a research sample selected under the stated scope. They do not represent all agent papers from January and should not be interpreted as absolute field popularity.
- The papers use different models, environments, budgets, and judges. The numbers in the table cannot be combined into a cross-paper ranking.

## Follow-up

- Whether MCP expands from single-server tool calls to cross-server transactions, permission boundaries, and verification of post-execution effects.
- Whether memory evaluation moves from question-answer recall to action utility, error accumulation, and safe forgetting in multi-session tasks.
- Whether agent RL develops low-cost, verifiable intermediate credit-assignment methods rather than depending only on terminal trajectory rewards.
- Whether GUI, coding, and research agents release sustainably runnable environments, traces, and evaluators that support cross-framework reproduction.
