# Agent Papers Monthly Review | 2026-02

[中文](2026-02.md) | English

> Type: historical retrospective. This review is organized by the UTC first-submission date of arXiv `v1` and was compiled retrospectively on 2026-08-02. These entries are not presented as results of a daily selection process that was already running in February.

## Scope and Count

- Period: 2026-02-01 to 2026-02-28, based on the first submission date of arXiv `v1`.
- Selected: 24 papers. Each paper's ID, official title, first submission date, and abstract were checked directly against its official arXiv abstract page.
- Research scope: agent training, memory, environment synthesis, multi-agent orchestration, computer use, coding agents, research agents, evaluation, and safety.
- Selection boundary: papers were retained for agent-specific contributions in interaction, state, environment, organization, training, or evaluation. Papers using an agent only as an application interface were excluded.
- Cross-month note: MCP-Atlas was first submitted as `v1` on 2026-01-31 and has therefore been moved to the [January review](2026-01.en.md). It is not counted again here merely because its arXiv ID begins with `2602`.

## Monthly theme

**Training signals expanded from trajectory outcomes to critical steps, while evaluation expanded from static tasks to dynamic environments, cross-session memory, and industrial codebases.**

February's work concentrated more strongly on how to form executable and verifiable agent training loops. CSO, BranPO, IntentRL, UI-Mem, WideSeek-R1, and ScaleEnv improved training through critical decisions, branch sampling, user intent, experience memory, multi-agent width, and environment generation, respectively. At the same time, Gaia2, MemoryArena, SWE-Bench Mobile, ContextBench, AIRS-Bench, and CHAIN brought real-time change, long-term dependency, industrial repositories, context localization, scientific workflows, and physical causality into evaluation.

## Trend analysis

### 1. Agent RL Began to Seek Local, Verifiable Credit Signals

CSO supervises only critical decisions that reverse outcomes, BranPO compares branches with the same prefix and different outcomes, and UI-Mem uses structured experience to guide online exploration. Compared with broadcasting a terminal reward over an entire trajectory, these methods aim to reduce long-horizon credit-assignment noise. Their shared risk is that bias in local verifiers, surrogate environments, or user simulators may be amplified by the policy; the reported results still require verification in a common real environment.

### 2. Environments Became Core Assets for Scalable Training Systems

ScaleEnv generates interactive tool environments from scratch, AgentSkiller generates cross-domain MCP services and consistent databases, SWE-World replaces Docker with a learned execution surrogate, and Gaia2 provides continuously changing asynchronous environments. Limits on training scale are shifting from model parameters toward environment count, state consistency, evaluator correctness, and rollout throughput.

### 3. Multi-Agent Systems Were No Longer Assumed to Be Stronger by Default

Agent Scaling explains heterogeneous gains through effective information channels, Entropy Perspective reports that a single agent is better on a substantial fraction of examples, AOrchestra dynamically chooses sub-agent configurations, and WideSeek-R1 trains parallel organization specifically for broad information gathering. The direction shifted from stacking fixed roles to deciding when to parallelize, what diversity is needed, and how many additional agents are worth the cost.

### 4. Memory Evaluation Shifted from Fact Retention to Action Effects and Safety Boundaries

PersistBench studies memories that should no longer be used, MemoryArena requires early experience to change later task behavior, UI-Mem transfers failure patterns and workflows to new applications, and MemFly optimizes the compression–relevance trade-off. Compared with January's many memory architectures, February emphasized action utility, forgetting conditions, and cross-task transfer.

### 5. Evaluation Environments Became More Realistic, but Judge Risk Remained

SWE-Bench Mobile introduces production iOS repositories and multimodal requirements, Gaia2 introduces independent temporal change, CHAIN introduces physical causality, ContextBench provides human-annotated code context, and AIRS-Bench omits baseline code. As realism increases, work such as LPS-Bench still uses LLM judges and SWE-World uses a learned execution surrogate; these evaluators themselves require tests for consistency, bias, and exploitability.

## Evidence and reproducibility limits

- Core contributions and reported numbers primarily come from official arXiv abstracts. Code, data, and results were not independently run, downloaded, and recomputed for all 24 papers.
- arXiv entries may change titles, experiments, or release status in `v2` and later versions. Month assignment is fixed to the first submission date of `v1`.
- The papers use different models, tools, budgets, environments, and judges. Success rates and relative improvements in the table are not directly comparable.
- Some work uses LLM judges, user simulators, learned surrogate environments, or synthetic tasks. These components enable scale but may also introduce systematic bias.
- The 24 papers are selected examples based on agent research questions, not every relevant February preprint. Exclusion does not imply lower paper quality.

## Follow-up

- Whether critical-step supervision and branch sampling transfer from retrieval tasks to GUI, coding, and embodied environments while preserving their gains.
- Whether synthetic-environment work releases execution traces, evaluator tests, and deduplication strategies so that environment errors do not become training shortcuts.
- Whether multi-agent systems report strong single-agent baselines under equal token, latency, and tool budgets.
- Whether memory systems jointly measure action utility, error propagation, privacy, forgetting, and storage cost.
- Whether dynamic environments and surrogate executors provide independently replayable state snapshots, versions, and random seeds.
