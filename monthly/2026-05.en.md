# Monthly Agent Paper Review | 2026-05

[中文](2026-05.md) | English

> Type: retrospective monthly review. This page was compiled retrospectively from official arXiv metadata and paper abstracts and is organized by initial submission date. Retrospective entries are not presented as if they had been selected by the daily automation at the time.

## Scope and Volume

- Period: 2026-05-01 to 2026-05-31, based on the arXiv `published` field.
- Selected papers: 24.
- Topics covered: memory and context, skills and harnesses, reasoning and planning, agent training, process evaluation, tool security, and runtime efficiency.
- Selection boundary: only papers whose primary research subject is an agent mechanism, execution environment, or process evaluation are included. General application papers that merely use the term “agent” in the abstract are excluded.

## Monthly theme

**Memory moved from a standalone component toward a complete lifecycle, while skills and harnesses began to be treated as executable, auditable system boundaries.**

May's central thread was not simply expanding memory capacity, but jointly addressing memory structure, portability, formation timing, cross-scenario evaluation, and provenance security. A second clear change was that skills were no longer just prompt text: research began to measure skill-library scaling, skill generation, runtime intervention, and supply-chain risk. Evaluation also shifted from final-state success toward control decisions, trajectory quality, permissions, and information flow.

## Trend analysis

### 1. Memory research moves from “can it recall?” to the full lifecycle

This month's papers jointly cover memory format, formation timing, consolidation cost, cross-model transfer, multi-party state, provenance, and cross-environment evaluation. LongMemEval-V2, EvoMemBench, and MemGym respectively isolate memory contributions through experience questions, a unified protocol, and executable environments. A single conversational QA score is therefore no longer sufficient to characterize agent memory.

### 2. Skills become executable artifacts—and new security principals

HASP turns skills into triggerable program functions; SkillGenBench directly evaluates skill generation; skill scaling laws show routing degradation as libraries grow; AgentTrap measures side effects from third-party skills at runtime. The shared change is that skills need version, permission, execution, and evaluation semantics, not only natural-language descriptions.

### 3. Evaluation expands from final-state correctness to trajectories, control, and information flow

HarnessAudit, AgentAtlas, POLAR-Bench, and AgentSecBench focus on permission boundaries, control decisions, privacy–utility, and non-interference respectively. All reject final answers as the sole criterion: unauthorized reads, information leakage, or faulty control during execution are failures even when the task is completed.

### 4. Agent training combines sparse terminal rewards with local feedback

Both SDAR and SERL preserve environment-level terminal rewards as the primary signal, then use token-level teacher information or step-level environment feedback to improve long-horizon credit assignment. The emphasis is not simply on adding denser supervision, but on controlling feedback reliability, placement, and weight so that an erroneous teacher or irrelevant context does not degrade the policy.

### 5. Harness and context serving become measurable variables

The Agentic Search experiments show that the same retrieval algorithm can produce different results under different harnesses and tool-return formats. Parallel Context Compaction and RecMem bring latency, write cost, and compaction scheduling into the research scope. Future model or algorithm comparisons need to hold the harness, state management, and serving strategy fixed or report them explicitly.

- Titles, arXiv IDs, initial submission dates, and abstract-level contributions were checked item by item against the official arXiv API on 2026-08-02. Dates use `published`, not later version-update times.
- Method effects in the table are author-reported. This review did not independently reproduce experiments and does not interpret abstract-level figures as a leaderboard that is directly comparable across papers.
- The 24 papers are a targeted sample directly related to agents. They do not represent all papers published in May and are not ranked by social-media attention.
- Position and framework papers are selected for the value of their problem definitions or system boundaries; inclusion does not imply large-scale empirical support.

## Follow-up

- Whether skill permissions move from offline scanning toward runtime capability control, and whether MCP tool surfaces acquire clearer authorization semantics.
- Whether memory systems retain gains across tasks and models while reporting construction, retrieval, and generation costs separately.
- Whether long-horizon training transfers reliably across environments without policy degradation from erroneous feedback.
- Whether process-level evaluations begin to include replayable trajectories, deterministic judges, and failure-localization tools.
