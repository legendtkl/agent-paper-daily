# Agent 论文分类体系

分类按论文试图解决的主要研究问题组织，而不是按模型名称、实验环境或应用名称组织。每篇论文保留一个主分类和最多三个辅助分类；主分类用于归档和统计，辅助分类仅用于检索。

## 判定原则

- 主分类取决于论文的首要贡献对象。
- 基准、评分方法和评测可靠性归入 `EV`；安全机制归入 `SS`；运行时和系统优化归入 `SY`。
- 依赖可执行环境并优化模型权重的训练归入 `AT`；部署后基于执行经验持续适应归入 `LT`。
- 只有论文贡献依赖特定任务环境时，才优先归入 `CU`、`SE`、`EA` 或 `RA`。

## 核心机制

这组分类回答 Agent 如何组织控制、规划、调用能力、保持状态、学习和协作。

| 代码 | 分类 | 覆盖范围 |
|---|---|---|
| <a id="af"></a>`AF` | Agent 架构与编排 | 控制流、模块接口、工作流图、运行时抽象和自修改架构。 |
| <a id="rp"></a>`RP` | 推理、规划与搜索 | 状态建模、任务分解、候选搜索、验证和预算。 |
| <a id="tu"></a>`TU` | 工具使用、行动与协议 | 工具发现、Schema、编排、协议、事务和效果核验。 |
| <a id="km"></a>`KM` | 记忆、上下文与知识 | 写入、组织、检索、更新、遗忘和知识治理。 |
| <a id="lt"></a>`LT` | 学习、适应与自我改进 | 部署后基于执行经验持续适应，包括反思、记忆更新、工作流或工具改进，以及可回滚的长期自修改。 |
| <a id="ma"></a>`MA` | 多 Agent 协作与组织 | 角色、工件、通信、拓扑、裁决和组织治理。 |

## 应用与环境

这组分类回答 Agent 机制如何进入数字界面、软件仓库、物理世界和研究任务。

| 代码 | 分类 | 覆盖范围 |
|---|---|---|
| <a id="cu"></a>`CU` | Web、GUI 与 Computer Use | Web、移动端、桌面、视觉 Grounding 和跨应用工作流。 |
| <a id="se"></a>`SE` | 软件工程与 Coding Agent | 仓库理解、Issue 修复、测试、需求澄清和长期维护。 |
| <a id="ea"></a>`EA` | 具身与机器人 Agent | 机器人任务、技能、VLA、连续控制和物理安全。 |
| <a id="ra"></a>`RA` | 深度研究、科学与数据 Agent | 深度检索、证据综合、代码实验、科学自动化和审计。 |

## 质量与工程

这组分类回答 Agent 如何评测、约束、恢复和高效运行。

| 代码 | 分类 | 覆盖范围 |
|---|---|---|
| <a id="ev"></a>`EV` | 评测与基准 | 环境、终态、轨迹诊断、评分可靠性和预算公平。 |
| <a id="ss"></a>`SS` | 可靠性、安全与安全工程 | 注入、越权、信息流、能力隔离、供应链和持续保障。 |
| <a id="sy"></a>`SY` | Agent 运行时、系统与效率 | 调度、沙箱、状态、检查点、观测与训练—执行桥。 |

## 基础与使能

这组分类回答基座模型属性、训练方法与多模态感知如何决定 Agent 的能力上限。

| 代码 | 分类 | 覆盖范围 |
|---|---|---|
| <a id="bm"></a>`BM` | 基座模型属性与能力上限 | 有效上下文、结构化输出、思考位置、视觉计价、缓存失效、规模与外壳的交互。 |
| <a id="pt"></a>`PT` | 模型后训练 | 奖励来自偏好、标注、规则或可验证答案，不需要可执行环境。 |
| <a id="at"></a>`AT` | Agent 端到端训练 | 使用可执行环境的真实终态产生训练信号，并据此优化模型权重与行动策略。 |
| <a id="mv"></a>`MV` | 多模态感知与 Grounding | 高分辨率、OCR、Grounding、时序状态和动作接口。 |

## 常见边界

| 容易混淆的分类 | 判定方式 |
|---|---|
| `EV` 与 `SS` | 主要贡献是发现、测量或评分问题时归 `EV`；主要贡献是阻止、隔离或缓解风险时归 `SS`。 |
| `SY` 与 `AF` | 主要改进执行基础设施、调度、状态或效率时归 `SY`；主要改变 Agent 控制结构或模块编排时归 `AF`。 |
| `AT` 与 `LT` | 在可执行环境中用终态信号优化模型权重时归 `AT`；部署后基于执行经验持续适应时归 `LT`。 |
| `PT` 与 `AT` | 不依赖可执行环境的偏好、规则或答案奖励归 `PT`；依赖环境真实终态的训练归 `AT`。 |
| `MV` 与 `CU` | 主要贡献是感知、OCR 或 Grounding 能力时归 `MV`；主要贡献是完成 Web、桌面或移动端任务时归 `CU`。 |
| `RP` 与 `RA` | 通用规划、搜索和验证机制归 `RP`；贡献依赖深度研究、科学或数据分析任务时归 `RA`。 |
