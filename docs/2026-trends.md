## 跨月趋势

### 1. 记忆从检索附件走向状态生命周期

1 月已经出现可学习的记忆操作、时间层级和多模态记忆评测；2—3 月进一步区分写入、检索、利用和跨会话影响；4 月补入遗忘、删除与有状态运行时；5 月集中处理结构化、巩固时机、迁移、来源链和跨环境评测；7 月的 Metis 则把记忆状态直接放进模型主干。变化不是简单扩大上下文，而是覆盖写入、检索、更新、迁移、删除、安全和评测的完整生命周期。

### 2. 评测从最终分数走向任务、轨迹、验证器三层审计

1—2 月的工作开始诊断工具选择、关键步骤和长期依赖；3 月出现步骤级标签、约束检查和 Judge 元评测；4—6 月把重复可靠性、动态故障、用户澄清、权限与信息流纳入评测；7 月的 DeepSWE、DynamicMCPBench、PAIChecker 和 OSReward 分别审计功能实现、环境效果、任务配对和奖励模型。可靠结论需要同时检查任务定义、执行轨迹和评分器，而不是只引用排行榜终态分数。

### 3. 训练信号越来越依赖真实执行反馈

2 月的关键步骤奖励、环境生成与经验记忆，3 月的约束验证和真实工具轨迹，5 月的选择性 hindsight distillation，都在缩短训练信号与环境效果之间的距离。7 月进一步出现可验证搜索环境、自演化 On-Policy Distillation、真实 Harness 强化学习和 MLE 程序演化。收益是目标更接近实际任务；风险是环境漏洞、验证器偏差、运行成本和 Harness 特性也会进入优化过程。

### 4. Harness 与运行时成为独立研究层

从 Agent OS、POSIX 进程、资源管理和上下文压缩，到 Harness 安全审计、技能执行、行为定位和 Harness 内训练，模型外系统不再只是实验脚手架。它决定 Agent 能看到什么、如何保存状态、能调用什么、何时恢复以及如何接受评测。因此跨论文比较需要报告 Harness、工具返回格式、状态策略、预算和环境版本。

### 5. 安全边界从提示防护下沉到能力和信息流

3 月的记忆控制流、工具链漏洞和数据过度暴露，4 月的最小能力集、后门工具和长序列风险，5—6 月的技能供应链、MCP 服务、来源证明和 Intent-to-Execution Integrity，共同把安全强制点推向模型外部。7 月的自适应攻击和运行时 Guardrail 进一步说明，固定攻击池或单一系统提示不足以证明安全性。

### 6. 应用环境从封闭任务走向真实工作流

Computer Use、终端、工业代码库、科学研究、真实设备和交互世界模型持续增加。评测对象随之从单轮正确率扩展到长时执行、跨应用状态、用户澄清、恢复能力、成本和权限。真实环境提高外部有效性，也带来不可重复状态、数据污染、平台差异和高复现成本。

## 方法与证据变化

| 研究环节 | 年初常见做法 | 1—7 月出现的变化 | 仍需解决的问题 |
|---|---|---|---|
| 训练 | 固定轨迹、终态稀疏奖励 | 关键步骤信号、自生成经验、可执行验证、Harness 内 RL | 奖励偏差、环境漏洞、成本与跨环境迁移 |
| 记忆 | 检索式外部模块 | 可学习写入、主动遗忘、来源链、跨 Agent 迁移、原生状态 | 长期压缩损失、删除证明、隐私和统一评测 |
| 评测 | 最终答案或单次成功率 | 过程标签、约束、重复运行、效果检查点、Judge 元评测 | 验证器真值、版本漂移、预算公平和独立复现 |
| 系统 | 隐式 Agent 循环 | 显式运行时、状态契约、技能工件、Harness 定位与训练 | 可移植接口、故障恢复、权限治理和观测成本 |
| 安全 | 提示拒绝、固定攻击集 | 信息流、能力控制、供应链、自适应攻击和运行时防护 | 组合攻击、真实部署基线、误报与性能开销 |

## 观察边界

- 165 篇是按 Agent 相关性与技术价值整理的定向样本，不提供领域论文总量或增长率估计。
- 1—7 月没有对应的完整历史每日筛选流水线；月报按 arXiv 官方 `v1` 首次提交日期归月，不能用篇数反推当时的日常入选频率。
- 表中实验结果属于作者报告，月报核验了元数据和摘要，但没有完成 165 篇独立实验复现。
- 新预印本会持续修订；代码、数据、许可证和社区评价需要在后续月报中复查。
- 社区互动量只作为传播证据，不作为论文质量或技术有效性的替代指标。
