## 跨月趋势

### 1. 记忆从功能模块走向状态治理

2—3 月主要回答如何持久化和组织 Agent 记忆，4 月补入可控遗忘与隐私边界，5 月进一步关注可移植性和长期评测，7 月则出现把记忆直接纳入基础模型设计的路线。变化不是简单地扩大上下文，而是逐步覆盖写入、检索、迁移、删除和评测的完整生命周期。

### 2. 评测从结果分数走向执行过程

早期工作更多测量任务结果；到 5—6 月，长程记忆、规划诊断、软件工程交互和真实桌面任务开始强调中间状态、澄清过程与失败恢复；7 月的终端、生产框架和奖励模型研究进一步暴露评测器偏差。可靠结论需要同时检查任务定义、环境、轨迹和评分器。

### 3. 训练信号越来越依赖真实环境

研究路线从离线数据和答案级奖励，逐步转向可执行环境中的终态验证、On-Policy 轨迹和 Harness 内训练。7 月的多篇工作把验证器或环境反馈直接接入自蒸馏、强化学习和递归改进流程。收益是训练目标更接近实际任务，风险是环境漏洞、奖励偏差和高运行成本也会进入优化闭环。

### 4. Harness 与运行时成为一等研究对象

协议、Agent OS、沙箱、状态、数据流水线和 Harness 不再只是实验脚手架。它们开始决定 Agent 能看到什么、能修改什么、如何恢复以及如何被评测。模型结果因此不能脱离外壳实现直接比较，系统设计也需要独立记录和复现。

### 5. 应用环境从封闭任务走向真实交互

桌面、终端、软件仓库、真实设备和交互世界模型的占比在样本中持续上升。能力评价随之从单轮正确率转向长时执行、跨应用状态维护、成本和安全。真实环境提高外部有效性，也带来不可重复状态、权限差异和数据污染等新变量。

## 观察边界

- 本页描述的是精选样本中的方向变化，不提供领域论文总量或增长率估计。
- 2026 年 1—6 月没有对应的完整每日筛选流水线，不能与 7 月及后续常态更新直接比较篇数。
- 新预印本会持续修订；代码、数据和社区评价需要在后续月报中复查。
- 社区互动量只作为传播证据，不作为论文质量或技术有效性的替代指标。
