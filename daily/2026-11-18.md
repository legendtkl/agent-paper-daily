## 入选论文

- [MCP 工具调用：Code Mode 比路由更关键](../papers/2026/11/2611.19123.md)（93 分，主分类 [`TU`](../docs/categories.md#tu)；辅助 [`SY`](../docs/categories.md#sy)、[`EV`](../docs/categories.md#ev)）：119 个封闭测试实例、3 个模型和 1,785 次串行运行显示 code mode 相对 plain MCP 减少 70%～90% token；中心假设「路由 + code mode 优于 code mode」未得到显著支持。公开轨迹可重算主表，但环境是单一合成 MCP 世界，不能直接外推到真实 server、权限和网络延迟。
- [Agent 记忆不只要答对，还要可控](../papers/2026/11/2611.20144.md)（94 分，主分类 [`EV`](../docs/categories.md#ev)；辅助 [`KM`](../docs/categories.md#km)、[`SS`](../docs/categories.md#ss)）：HEAMS 用统一接口覆盖性能、效率、隐私、安全和用户主权；HippoRAG 在隐私任务中 94.79% helpful，同时 71.74% 的任务发生泄漏。治理层能降低泄漏和污染，但伴随 helpfulness／允许召回损失，且多数评分依赖未做人类一致性验证的 LLM judge。

## 候选观察

- [2611.19752](https://arxiv.org/abs/2611.19752)（90 分，`EV`／`KM`）：StaleBench 用 892 个真实更新事实说明检索指标可能把记忆策略排反，并公开数据与实现；与当日 HEAMS 的记忆评测贡献部分重叠，先观察第三方复跑。
- [2611.20844](https://arxiv.org/abs/2611.20844)（89 分，`EV`）：DetourBench 为 25 个有限状态任务计算精确最短动作和剩余工作，375 条 episode 有可解释价值；任务规模小且环境约束较强。
- [2611.20922](https://arxiv.org/abs/2611.20922)（88 分，`KM`／`TU`）：Experience Rot 研究工具接口静默变化后经验反而伤害 Agent；摘要结论重要，但未取得论文专属公开代码与运行轨迹。
- [2611.21095](https://arxiv.org/abs/2611.21095)（88 分，`EV`／`SE`）：SWE-WhatIf 用 89 个真实会话构造自适应用户模拟，并有 16 人研究；用户模拟仍依赖记录重构，公开工件和第三方验证不足。
- [2611.20488](https://arxiv.org/abs/2611.20488)（87 分，`EV`／`CU`）：EVIDENT 用 220 个英韩任务分离表面成功与证据 grounding；未取得代码、标注和评测轨迹，关键比例暂不能独立核验。
- [2611.18642](https://arxiv.org/abs/2611.18642)（86 分，`KM`／`MA`）：56 个交互世界显示连续摘要造成 handoff loss，但首次提交为 2026-10-14，本批次是 cross-list，且未取得公开实现。
