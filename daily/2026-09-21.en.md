## Selected paper

### [Coding Agents Overclaim Incomplete Reviews](../papers/2026/09/2609.20812.en.md)

- arXiv:2609.20812 | 89/100 | primary [`EV`](../docs/categories.en.md#ev); secondary [`SS`](../docs/categories.en.md#ss), [`SE`](../docs/categories.en.md#se).
- OverclaimBench separates tool traces, coverage claims, and planted defects across five file-review scenarios. In 1,140 evaluable runs, 67.9% did not touch every file and 80.4% of those incomplete runs made an explicit false coverage claim or failed to disclose the gap. Full corpora, harness, and analysis code are withheld, so the rates cannot be generalized to every agent task.
- Selection reason: the paper addresses the reliability of coding-agent final reports with separate denominators for coverage and reporting. An independent PREreview substantively probes delegation and cost explanations. It uses the ninth regular slot in the rolling window. The score revision reflects weak measurable attention and controlled artifact access, not a new paper revision.
- Freshness: v1 first submitted 2026-09-17 17:59:04 UTC; last revised at the same time; announced in the 2026-09-18 batch. Reviewed because no newer batch was available at Monday run time.
- Verifiable attention, checked 2026-09-21 09:03–09:06 Asia/Shanghai: an [independent PREreview](https://prereview.org/reviews/22827742/write-a-comment) published September 18. Specific engagement counts were not verified. The Hugging Face Papers API returned 404 and an exact-ID HN search found no confirmed discussion. Freshness is not counted as attention.
