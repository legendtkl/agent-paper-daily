## Selected papers

- [Can agents build and improve RAG systems from scratch?](../papers/2026/11/2611.25582.en.md) (96; primary [`EV`](../docs/categories.en.md#ev), secondary [`RA`](../docs/categories.en.md#ra), [`SE`](../docs/categories.en.md#se), [`SY`](../docs/categories.en.md#sy)): AutoRAGBench gives agents one H800, six hours, and an open code space to build RAG systems for nine tasks, then freezes the artifact and evaluates validated evidence with five held-out readers. GPT-6.1 Sol + Codex CLI averages 56.08 versus 46.42 for Reference RAG. Eighteen evaluation-contract tests passed at a pinned commit; the 8 GB data and full experiment were not rerun.
- [Let agents design experiments, not just run workflows](../papers/2026/11/2611.26248.en.md) (97; primary [`EV`](../docs/categories.en.md#ev), secondary [`RA`](../docs/categories.en.md#ra), [`SY`](../docs/categories.en.md#sy)): TwinLab-Bench turns records from 52 real laboratories into interactive twins where agents design experiments and are scored against hidden truth. Expert-route replay averages 97.8 while the best model scores 45.0. Seventy-six percent of outputs come from records or same-lab calibrated calculators. Public code compiled statically; paid-model experiments were not reproduced.

## Watchlist

- [2611.25760](https://arxiv.org/abs/2611.25760) (94, `EV`/`SE`,`SS`): 37.24% of 435 sampled work reports contain an unfaithful claim and FaithDetector reaches 93.06% macro-F1. It partly overlaps yesterday's completion-evidence paper, and the replication package was not audited locally.
- [2611.26311](https://arxiv.org/abs/2611.26311) (93, `EV`/`SE`,`CU`): SWE-Recreation evaluates GUI exploration and rebuilding across 54 applications and 1,446 hidden requirements, but its listed code repository returned 404 at collection time.
- [2611.25066](https://arxiv.org/abs/2611.25066) (92, `EV`/`SE`,`SY`): DVBench covers 95 end-to-end UVM verification tasks and reports 21.05% best success. The repository is public, but has no repository-wide license and complete commercial EDA reproduction is expensive.
- [2611.25673](https://arxiv.org/abs/2611.25673) (91, `EV`/`KM`,`SY`): CompAct-Bench inserts compaction boundaries into successful trajectories and measures downstream loss; the project page is public, but code and complete trajectories were not found.
- [2611.25123](https://arxiv.org/abs/2611.25123) (91, `KM`/`SY`,`AT`): GrepMem uses an append-only log and regex retrieval, reporting 95–97% on ContextBench; the paper only promises a future release of code, prompts, and checkpoints.

## Gaps and recheck items

- AutoRAGBench was limited to static compilation and 18 tests. Its CPU example stopped as expected without the approximately 8 GB formal dataset. H800, five-reader, and commercial-agent experiments were not rerun.
- TwinLab-Bench compiled statically and its public dataset lists 7,269 files. Full runs require Linux, bubblewrap, commercial CLIs, and model APIs. The dataset has no single license field, so reuse requires task-level checks.
- TwinLab-Bench had 5 Hugging Face votes and no comments; the repositories had 3 and 4 stars. Hacker News had no exact hit; six requested Reddit communities returned HTTP 403; exact public X search produced no verifiable post. Access gaps do not establish absence of discussion.
