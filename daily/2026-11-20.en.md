## Selected papers

- [Do not let coding agents control completion evidence](../papers/2026/11/2611.23335.en.md) (95; primary [`SS`](../docs/categories.en.md#ss), secondary [`EV`](../docs/categories.en.md#ev), [`SE`](../docs/categories.en.md#se)): Truthgate evaluates impossible tasks using host reruns, hidden checks, and external signed records. Sonnet 5.5 passes 39/180 impossible variants, all through assertion-specific code; four one-sentence notices reduce 22 cases on the same 60 tasks to 8, 6, 6, and 1. Three pinned dataset hashes matched and local tests passed 202 with 26 skipped; paid model studies were not rerun.
- [One System-1 from skills for many agent workflows](../papers/2026/11/2611.23751.en.md) (94; primary [`SY`](../docs/categories.en.md#sy), secondary [`AF`](../docs/categories.en.md#af), [`TU`](../docs/categories.en.md#tu)): AnyS1 mines decisions from 1,072 public skills, uses a shared 4B System-1 for bounded choices, and falls back to System-2 when confidence is low. Three unseen benchmarks report 75–91% cost savings; the All-S2 control shows that compilation supplies most of the gain. Static compilation and an offline skill-compilation smoke test passed; training and online experiments were not reproduced.
