## Selected papers

### [Distilling Verifiable Agent Skills from GitHub Repositories](../papers/2026/09/2609.02749.en.md)

- arXiv:2609.02749 | 97/100 | primary [`KM`](../docs/categories.en.md#km); secondary [`RA`](../docs/categories.en.md#ra), [`AF`](../docs/categories.en.md#af), [`EV`](../docs/categories.en.md#ev)
- Repo-To-Skill converts repositories into executable, test-backed Agent Skills and evaluates whether the resulting artifacts preserve behavior rather than merely summarize documentation.
- Selection rationale: The work combines repository analysis, generated skill files, verification tasks, and cost accounting. It was selected for making a skill an auditable engineering artifact with explicit acceptance tests. Main limits: Cross-model transfer and end-to-end cost including skill construction were not independently reproduced, and some gains may depend on the benchmark's repository and verifier design.
- Independent research note: [Distilling Verifiable Agent Skills from GitHub Repositories](https://bytedance.larkoffice.com/docx/JSh0dlB08o619Fx8MYacbxcLnlh).

### [Can Agents Build and Evolve Their Own Harnesses?](../papers/2026/09/2609.01437.en.md)

- arXiv:2609.01437 | 95/100 | primary [`EV`](../docs/categories.en.md#ev); secondary [`SE`](../docs/categories.en.md#se), [`LT`](../docs/categories.en.md#lt), [`AF`](../docs/categories.en.md#af)
- HarnessDev changes the unit of evaluation from a task answer to an executable, frozen, auditable harness, testing both creation from a weak seed and continued evolution from runtime feedback.
- Selection rationale: Creation spans six creator models, four domains, five downstream benchmarks, and 2,207 unique instances. Hidden tasks, frozen versions, runtime audits, and cross-executor comparisons expose the gap between writing a harness and improving it reliably. Main limits: Evolution often has one trajectory per setting, only two of nine declared versions were also best on held-out tasks, and code, generated artifacts, and complete traces were not public.
- Independent research note: [Can Agents Build and Evolve Their Own Harnesses?](https://bytedance.larkoffice.com/docx/UPd1dzKEho7kZVxTlB3ckXTgnzf).
