## Selected papers

### [Composable Infrastructure for Agent Evolution](../papers/2026/10/2610.32253.en.md)

- arXiv:2610.32253 | 95/100 | Primary [`SY`](../docs/categories.en.md#sy); secondary [`LT`](../docs/categories.en.md#lt), [`EV`](../docs/categories.en.md#ev), [`AF`](../docs/categories.en.md#af).
- RSIHub makes the agent-evolution lifecycle composable while keeping evaluation and certified evidence outside the mutable surface. Across four adapted methods, two seed agents, and two benchmarks, the largest overall gain is 13.5 points, but rankings are unstable. The repository and contracts are substantial and compile statically; full tests are blocked by a missing Rust toolchain for a pinned dependency, and the main experiments are not rerun.
- [Feishu independent review](https://bytedance.larkoffice.com/docx/OBwOdobu0oQuEuxwVWecQIN7njh)

### [Testing Agent Resilience with Realistic MCP Faults](../papers/2026/10/2610.32555.en.md)

- arXiv:2610.32555 | 95/100 | Primary [`EV`](../docs/categories.en.md#ev); secondary [`SS`](../docs/categories.en.md#ss), [`TU`](../docs/categories.en.md#tu), [`SY`](../docs/categories.en.md#sy).
- MCP-Injector calibrates an MCP fault profile from 57,240 public threads and lowers task-completion score from 8.08 to 3.23/10 across 1,350 cells; the resilience difference between 20B and 120B is not significant. GitLab and Zenodo release cell-level results and analysis mappings, and core modules compile; claims remain bounded to one model family, single-server tasks, and a permanent-heavy stress profile.
- [Feishu independent review](https://bytedance.larkoffice.com/docx/Obhod7cV9opzYYxm9iYcmSVfnjh)

## Data gaps and follow-up

- RSIHub's primary experiments use one run per task; only capability-preservation controls use three repetitions. Full tests stop because a pinned dependency needs an unconfigured Rust toolchain. Docker, commercial models, and ten-generation evolution are not run.
- Full MCP-Injector reproduction requires two local models, five classes of external API, roughly 58 agent-execution hours, and 18 judge-API hours. This run checks the artifact, manifest, and core code only.
- No verifiable independent reproduction was found for either paper. Exact Hacker News searches return zero stories; all six specified Reddit communities return HTTP 403; public-X search yields no verifiable original post. These are access and evidence gaps, not proof of no discussion.
