## Selected paper

### [Self-Improvement Must Change Both the Solution and the Harness](../papers/2026/11/2611.08946.en.md)

- arXiv 2611.08946; score 94; primary [`EV`](../docs/categories.en.md#ev), secondary [`LT`](../docs/categories.en.md#lt) and [`EA`](../docs/categories.en.md#ea).
- Flex-RSI uses an executor/improver loop to test whether an agent can improve both its solution and harness under fixed budgets and hidden splits. Validation improves in 85% of 177 runs, with a median gain of 10.4 points.
- Six of seven matched pairs score higher with the improver, but the sample is small and most self-improving runs use more rounds. The public code assumes a Linux sandbox, and the main experiments were not independently rerun.

- Python compilation passes at the pinned commit. On macOS, 157 tests pass and 11 skip; five fail on Linux assumptions involving `/proc` and `umount2`. The full suite and main experiments were not completed in this run.
- The Hugging Face Papers API does not list the paper; exact-ID searches on Hacker News and the six specified Reddit communities return no matches. Public X evidence was only indirectly verified, and unreliable engagement fields are not reported.
