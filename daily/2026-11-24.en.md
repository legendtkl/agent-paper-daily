## Observation list

- [2611.26897](https://arxiv.org/abs/2611.26897) (ProbeAgent, 95; primary [`EV`](../docs/categories.en.md#ev); secondary [`SY`](../docs/categories.en.md#sy), [`SE`](../docs/categories.en.md#se)): 22 agent configurations over ten benchmarks yield 1,244 failures and 536 failure-mode descriptions. Two annotators accept 90.0% of assigned descriptions and reject 83.3% of similar alternatives. The paper page still points to `HowieHwong/probeagent`, but both the repository API and Git clone return 404. Only 119 of 239 proposed explanations reach sibling testing, so the full construction and grouping pipeline remains unauditable.
- [2611.27116](https://arxiv.org/abs/2611.27116) (CoEvoBench, 94; primary [`EV`](../docs/categories.en.md#ev); secondary [`LT`](../docs/categories.en.md#lt), [`SY`](../docs/categories.en.md#sy)): across five agentic domains, the strongest researcher raises the Qwen3.5-9B-Base weighted average from 1.09 to 31.23, against 37.42 for the reference system. The author repository's default branch has no new commit since the previous review. The fixed commit still reports 376 passed, 48 skipped, and 7 failed tests locally, while the README's Docker/GPU acceptance and final-evaluation wiring gaps remain open.
- [2611.27182](https://arxiv.org/abs/2611.27182) (Tripwire, 93; primary [`SS`](../docs/categories.en.md#ss); secondary [`EA`](../docs/categories.en.md#ea), [`AF`](../docs/categories.en.md#af)): TRIP lets an agent write lightweight interrupts for a continuously executing robot policy. On 168 RoboHD scenes, safety for the strongest policy rises from 61.3% to 81.3%, while task success is 38.7% versus 31.0%. No paper-specific implementation is public. Real-robot evidence covers only two tasks and ten tabletop setups, and the simulator pauses physics while the agent or VLM computes.
- [2611.27860](https://arxiv.org/abs/2611.27860) (SplitBench, 94; primary [`EV`](../docs/categories.en.md#ev); secondary [`SS`](../docs/categories.en.md#ss), [`SE`](../docs/categories.en.md#se)): SplitBench separates untrusted test execution from trusted grading. It converts 180 of 202 Terminal-Bench and DeepSWE tasks, agrees with native graders in 98.7% of 1,356 comparisons, and reports that none of 360 adversarial attempts passed through a SplitBench flaw. The paper still says that the full artifact will be released upon publication, leaving the converted tasks, attack records, and Table 5 recomputation script unavailable for audit.
