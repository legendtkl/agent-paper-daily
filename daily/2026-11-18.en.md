## Selected papers

- [MCP Tool Use: Code Mode Matters More Than Routing](../papers/2026/11/2611.19123.en.md) (93; primary [`TU`](../docs/categories.en.md#tu), secondary [`SY`](../docs/categories.en.md#sy) and [`EV`](../docs/categories.en.md#ev)): 119 sealed-test instances, three models, and 1,785 serial runs show 70–90% token reductions for code mode versus plain MCP. The central router-plus-code hypothesis is not significant. Public traces reproduce the tables, but the single synthetic MCP world does not establish real-server, permission, or network-latency effects.
- [Agent Memory Must Be Correct and Controllable](../papers/2026/11/2611.20144.en.md) (94; primary [`EV`](../docs/categories.en.md#ev), secondary [`KM`](../docs/categories.en.md#km) and [`SS`](../docs/categories.en.md#ss)): HEAMS evaluates performance, efficiency, privacy, security, and sovereignty through one interface. HippoRAG is helpful on 94.79% of privacy tasks while leaking on 71.74%. Governance reduces leakage and poisoning at a helpfulness/allowed-recall cost, and most judges lack human-agreement validation.

## Watch list

- [2611.19752](https://arxiv.org/abs/2611.19752) (90, `EV`/`KM`): StaleBench uses 892 real changing facts to show retrieval metrics can reverse memory-policy rankings and releases data and code. Its evaluation contribution overlaps today's HEAMS selection; await independent reruns.
- [2611.20844](https://arxiv.org/abs/2611.20844) (89, `EV`): DetourBench computes exact shortest action paths and residual work for 25 finite-state tasks and 375 episodes; the task set is small and strongly constrained.
- [2611.20922](https://arxiv.org/abs/2611.20922) (88, `KM`/`TU`): Experience Rot studies prior experience becoming harmful after silent tool-interface changes; no paper-specific code or run traces were retrieved.
- [2611.21095](https://arxiv.org/abs/2611.21095) (88, `EV`/`SE`): SWE-WhatIf builds adaptive user simulation from 89 real sessions and includes a 16-user study; public artifacts and third-party validation remain limited.
- [2611.20488](https://arxiv.org/abs/2611.20488) (87, `EV`/`CU`): EVIDENT separates surface success from evidence grounding over 220 English/Korean tasks; code, labels, and trajectories were not retrieved.
- [2611.18642](https://arxiv.org/abs/2611.18642) (86, `KM`/`MA`): 56 interactive worlds expose handoff loss under repeated summarization, but the first submission was October 14, this batch is a cross-list, and no implementation was retrieved.
