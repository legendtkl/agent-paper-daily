## Selected papers

### [Agent Reliability on Long-Dependency API Workflows](../papers/2026/09/2608.29128.en.md)

- arXiv:2608.29128 | 94/100 | primary [`EV`](../docs/categories.en.md#ev); secondary [`TU`](../docs/categories.en.md#tu), [`SS`](../docs/categories.en.md#ss)
- APIFlow-Bench evaluates long REST workflows with deterministic worlds, terminal-state checks, and source-sensitive delivery scoring, separating correct state changes from incorrect final reporting.
- Selection rationale: The release covers 19 models, 467 tasks, and 44,362 traces. Clean 20-subtask chains passed at 74.4% versus 92.9% for single tasks; 169 of 219 clean failures reached the correct state but failed final delivery. Main limits: About 8% of chain trials were affected by instruction-rewrite omissions, only 11 worlds supported the 20-step claim, and task and oracle generation share a model-family bias.
- Independent research note: [Agent Reliability on Long-Dependency API Workflows](https://bytedance.larkoffice.com/docx/I7j4dnVhkolUfax3ZU1czJMen3b).

### [The Benefit Boundary of Verification Tools for Coding Agents](../papers/2026/09/2608.28795.en.md)

- arXiv:2608.28795 | 89/100 | primary [`EV`](../docs/categories.en.md#ev); secondary [`SE`](../docs/categories.en.md#se), [`SY`](../docs/categories.en.md#sy)
- The study isolates how startup probes, shell access, and screenshots change coding-agent outcomes instead of comparing whole harnesses as indivisible packages.
- Selection rationale: Across 1,116 builds, six models, and eight tool configurations, a startup probe raised launch success from 86.5% to 99.5%; full shell access mainly helped concurrency, restart, and ordering stress tests. Main limits: A single human scorer, a non-interactive screenshot tool, and one application domain limit generalization. The listed GitHub repository returned 404, although a Zenodo archive was reachable.
- Independent research note: [The Benefit Boundary of Verification Tools for Coding Agents](https://bytedance.larkoffice.com/docx/WVKFdzwBKokzuSxHJDNcl1Vqn1e).
