## Selected papers

### [Having Coding Agents Build Deployable Agents](../papers/2026/09/2609.04611.en.md)

- arXiv:2609.04611 | 96/100 | primary [`EV`](../docs/categories.en.md#ev); secondary [`SE`](../docs/categories.en.md#se), [`AF`](../docs/categories.en.md#af), [`SY`](../docs/categories.en.md#sy)
- Tau-squared-Bench evaluates Coding Agents that must recover requirements from conflicting business records and customers, inherit or rewrite code, connect production APIs, and deliver an executable Agent under cost and latency constraints.
- Selection rationale: Fifty-three tasks span four domains. The best configuration scored 23.9% versus an 82.2% author-built oracle ceiling; traces show shallow evidence search, little customer questioning, weak architecture exploration, and self-tests rewritten to match faulty implementations. Main limits: Each task-configuration pair has one build, one simulator model drives customers and users, banking dominates the task mix, and a complete run is expensive.
- Independent research note: [Having Coding Agents Build Deployable Agents](https://bytedance.larkoffice.com/docx/OttbdMG4EoLf00xQdyYcCAwUnXb).

### [Multi-Agent Search for TPU Kernel Optimization](../papers/2026/09/2609.04523.en.md)

- arXiv:2609.04523 | 93/100 | primary [`SE`](../docs/categories.en.md#se); secondary [`MA`](../docs/categories.en.md#ma), [`RP`](../docs/categories.en.md#rp), [`SY`](../docs/categories.en.md#sy)
- MaxKernel combines planning, implementation, compilation repair, frozen tests, autotuning, profiling, and graph search to generate TPU Pallas kernels from measured hardware feedback.
- Selection rationale: Parallel and beam search reached 50/50 compilable and correct tasks with 1.58x and 1.49x geometric-mean speedups. On eight expert tasks, parallel search reached 2.32x versus 2.02x for handwritten Pallas, with five independent Auto runs. Main limits: All LLM calls used one model, tests ran on a single TPU v6e device, some tolerances were as loose as 1e-1, and total token and TPU search cost were not reported.
- Independent research note: [Multi-Agent Search for TPU Kernel Optimization](https://bytedance.larkoffice.com/docx/YBfOdHw6AoNqV4x0X6TcXapzn9f).
