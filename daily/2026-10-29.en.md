## Selected papers

### [Capability-organized recursive Harness improvement](../papers/2026/10/2610.36077.en.md)

- arXiv:2610.36077 | 93/100 | Primary [`LT`](../docs/categories.en.md#lt); secondary [`AF`](../docs/categories.en.md#af), [`SY`](../docs/categories.en.md#sy), [`MV`](../docs/categories.en.md#mv).
- The Trinity combines capability-tree diagnosis, module generation, and selective inheritance into four rounds of Harness improvement. Oracle means across 28 training and 18 unseen benchmarks rise from 39.06/37.45 to 73.16/63.61. Deployable self-routing reaches only 71.27/60.96, and one frozen backbone with no independent reruns prevents treating the Oracle bound as deployed performance.

### [Predicting when an Agent needs intervention](../papers/2026/10/2610.36471.en.md)

- arXiv:2610.36471 | 92/100 | Primary [`EV`](../docs/categories.en.md#ev); secondary [`SY`](../docs/categories.en.md#sy), [`CU`](../docs/categories.en.md#cu), [`SS`](../docs/categories.en.md#ss).
- ReInBench turns error self-recovery into a dataset of 1,259 traces and 1,403 events. ReCoF reaches Macro-F1 of 73.53, 74.18, and 72.99 on three source models. Public data and fixed splits were verified, but completion correlations are not causal intervention effects and the code snapshot was not locally validated.
- [Feishu research note](https://bytedance.larkoffice.com/docx/APGpd4BbXodq80xeN9gcKlnlnuw)

## Evidence gaps and follow-ups

- The Trinity lacks complete code and a license. One backbone, no independent reruns, the Oracle/self-router gap, and small robot samples constrain the claim.
- The ReInBench code snapshot was not locally validated, the Web subset lacks original screenshots/full DOM, and the recovery/completion association has not been tested through online intervention.
- Neither paper includes screenshots: exact text and table values communicate the methods, results, and limitations more precisely.
- Exact-title Hacker News searches returned 0; all six specified Reddit communities returned HTTP 403; public X search yielded no verifiable original post. These are retrieval gaps, not evidence of no discussion.
